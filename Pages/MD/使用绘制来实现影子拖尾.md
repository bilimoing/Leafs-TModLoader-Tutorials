## **实现影子拖尾：记录与绘制**

### **记录：打点计时器**

#### **自制的记录方式**

首先，我们需要每隔一会记录弹幕所处的位置，以知道我们应该将拖尾绘制在何处。

这类似打点计时器，不过这次这个间隔由你自己决定。

我们使用Vector2的列表来记录这些位置，就像这样：

```csharp
private Vector2[] oldPosi = new Vector2[16];
private int frameTimer = 0;

public override void AI()
{
    frameTimer++;
    
    if (frameTimer % 2 == 0)  // 每两帧记录一次
    {
        for (int i = oldPosi.Length - 1; i > 0; i--)
        {
            oldPosi[i] = oldPosi[i - 1];
        }
        oldPosi[0] = Projectile.Center;
    }
    
    // 弹幕贴图朝上时的旋转角度（如果贴图朝向不同，调整这里）
    Projectile.rotation = Projectile.velocity.ToRotation() + MathHelper.PiOver2;
}
```

#### **使用原版的记录方式**

实际上，原版就有一种记录弹幕路径的方式，它的使用方法大致是这样的：

```csharp
public override void SetDefaults()
{
    // 一些常规的弹幕设定：
    Projectile.height = 24;                    // 弹幕碰撞箱高度
    Projectile.width = 30;                     // 弹幕碰撞箱宽度
    Projectile.scale = 1f;                     // 贴图缩放比例
    Projectile.friendly = true;                // 是否为友方弹幕（能伤害敌怪）
    Projectile.hostile = false;                // 是否为敌方弹幕（能伤害玩家）
    Projectile.DamageType = DamageClass.Magic; // 伤害类型：魔法
    Projectile.aiStyle = -1;                   // AI 样式：-1 表示不使用原版预设 AI，由自己写
    Projectile.timeLeft = 450;                 // 存活时间（帧），450 帧 = 7.5 秒
    Projectile.extraUpdates = 1;               // 额外更新次数，1 表示每帧更新 2 次（速度翻倍的感觉）

    // 这里是重点：
    ProjectileID.Sets.TrailingMode[Projectile.type] = 0;      // 拖尾记录模式：0 = 只记录位置
    ProjectileID.Sets.TrailCacheLength[Projectile.type] = 30; // 拖尾缓存长度：记录最近 30 个位置
}
```

其中，`ProjectileID.Sets.TrailCacheLength[Projectile.type]` 顾名思义，代表的是记录的列表长度。你可以修改这个长度，但实际如何记录轨迹，取决于下一个属性，或者你自己手动定制。

一旦这个长度被设置，弹幕在 `SetDefaults` 时就会把 `oldPos`、`oldRot`、`oldSpriteDirection` 这几个数组扩容到指定大小。否则，这些数组一开始的长度都是一个固定值。

另外一个参数 `ProjectileID.Sets.TrailingMode[Projectile.type]` 是我们这次研究的重点，也就是如何记录轨迹。

拖尾记录模式（`TrailingMode`）决定了游戏为你缓存哪些历史数据，共有以下几种取值：

**-1（默认值）**：不记录任何拖尾数据。这是所有弹幕的默认值。

**0 （单记录）**：只记录位置。最常用，适合大多数普通拖尾。

**1 （无效值）**：这个是专门为原版部分弹幕定制的记录模式，会在分析源码时细讲，我们不应使用。官方文档标注为无效值。

**2 （全记录）**：记录位置、旋转和精灵朝向（`oldPos`、`oldRot`、`oldSpriteDirection`）。适合贴图会旋转的弹幕（如飞刀，激光剑）。

**3 （平滑记录）**：与 2 相同，但会对旧数据进行插值平滑，让拖尾更顺滑。

**4 （手持记录）**：与 2 相同，但旧数据会跟随弹幕拥有者移动，适合绑定在玩家身上的弹幕（如长矛，鞭子）。

设置好模式后，记得配合 `TrailCacheLength` 设置缓存长度。绘制时直接读取 `Projectile.oldPos`、`Projectile.oldRot` 等数组即可。

分析完成后，我们得知了：

在一般在模组开发过程中，普通弹幕常用的 `TrailingMode`（以下简称modeX） 只有 `0` 和 `2`。如果需要定制，一般是不使用原版的 `TrailingMode`，而是手动操作弹幕的 `oldPos`、`oldRot` 等属性。



**mode0**：仅仅记录坐标。

**mode1**：在弹幕存在帧图时，仅在 `frameCounter == 0`（即帧图切换完成后的一帧）或 `oldPos[0]` 还是零向量时记录位置。可能可以用它来干什么？

**mode2**：除了记录坐标，还记录了 `rotation` 与 `spriteDirection`。

**mode3**：记录方法很特殊。记录后会遍历所有记录过的点（`oldPos` 列表），假设其索引值为 n，那么当 n &gt; 0 时，会计算 `oldPos[n-1] - oldPos[n]` 的方向，并将 `oldRot[n]` 的值更改为这个方向。也就是说，在 mode3 下，`oldRot` 并不是记录下来之后便不再改变的。不过实际上在应用中，这一点小误差基本可以忽略，除非你有特别的需求。

**mode4**：在 `numUpdates == 0`（非额外更新帧）且该位置不是零向量时，会为记录的所有坐标额外加上一个玩家（所有者）在前一帧内的位移。



然而，在原版的所有追踪中，`oldPos` 记录下的都是 `Projectile.Position`，而不是我们最经常使用的 `Projectile.Center`。

### 处理数据：将新的坐标“Push”进列表中

每次“打点”时保存坐标的操作，具体来说就是：保存一个新的点，并删除列表中的最后一个点。代码如下：

```csharp
public static void Push<T>(T ele, ref T[] list)
// 使用泛型，使得我们能够在使用时再去定义它的类型。
// 之所以这样做，是因为 Push 操作不仅适用于 Vector2 的列表，
// 之后如果需要对别的类型的列表进行 Push 操作，我们也可以调用这个函数。
{
    for (int i = list.Length - 1; i > 0; i--)
    // 将所有元素“后移一格”，最后一个元素会被直接删除，位置 0 会被空出来
    {
        list[i] = list[i - 1];
    }
    list[0] = ele;  // 将我们想放入的元素放在列表的 0 位置
}
// 我将它放到了一个名为 Fucs 的类里，以便随时调用
```

至于如何使用，大概不用多说了：


### 绘制：DrawVector2ListDirect

```csharp
private Texture2D tex;
// 别忘了在 SetDefaults() 中加上：
// tex = ModContent.Request<Texture2D>("你贴图的路径").Value;

public static void DrawVector2ListDirect(
    SpriteBatch spriteBatch,
    Vector2[] vecList,
    Texture2D tex,
    float transparency,
    float scale,
    float turn,
    int advance = 1,
    float transparencyStep = 0,
    float scaleStep = 0
)
{
    for (int i = vecList.Length - 1; i > advance - 1; i--)
    {
        if (vecList[i] != Vector2.Zero)  // 遍历你的列表
        {
            spriteBatch.Draw(
                tex,
                Fucs.FixedDrawPosi(vecList[i]),
                null,
                Color.White * transparency * (1 - transparencyStep * i),
                (vecList[i - 1] - vecList[i]).ToRotation() + turn,
                tex.Size() * .5f,
                scale * (1 - scaleStep * i),
                SpriteEffects.None,
                0
            );  // 绘制拖尾
        }
    }
}

public static Vector2 FixedDrawPosi(Vector2 posi)  // 将世界坐标转换为屏幕坐标的函数
{
    return new Vector2(posi.X, posi.Y) - Main.screenPosition;
}
// 与上面那段一样，我也将它放到了一个名为 Fucs 的类里
```

我们来看一下它的参数：

- **spriteBatch**：这是一个绘制接口。毕竟这是个涉及绘制操作的函数，绘制接口是必不可少的。

- **vecList**：这是一个 `Vector2` 列表，代表所有需要绘制的点。

- **tex**：贴图，不作多解释。

- **transparency** 与 **scale**：分别是绘制贴图的初始透明度与大小。

- **turn**：即旋转量。如果你的贴图朝向并不是向左，你应该知道要做什么。

  接下来三个参数可填可不填，不过它们是重点。

- **advance**：使得弹幕绘制时可以无视前 advance 个坐标（注意不是后），用于做出“飞过后并不立马产生拖尾，而是延迟一会后产生拖尾”的效果。你可以试着修改这个值。

```csharp
using Microsoft.CodeAnalysis;
using Microsoft.Xna.Framework;
using Microsoft.Xna.Framework.Graphics;
using Microsoft.Xna.Framework.Graphics.PackedVector;
using Terraria;
using Terraria.Audio;
using Terraria.GameContent;
using Terraria.GameContent.ItemDropRules;
using Terraria.ID;
using Terraria.ModLoader;

namespace DemoMod.Content.Projectiles
{
    public class DemooldPosiProj : ModProjectile
    {
        public override void SetDefaults()
        {
            // 一些常规的弹幕设定：
            Projectile.height = 30;                    // 弹幕碰撞箱高度
            Projectile.width = 30;                     // 弹幕碰撞箱宽度
            Projectile.scale = 1f;                     // 贴图缩放比例
            Projectile.friendly = true;                // 是否为友方弹幕（能伤害敌怪）
            Projectile.hostile = false;                // 是否为敌方弹幕（能伤害玩家）
            Projectile.DamageType = DamageClass.Magic; // 伤害类型：魔法
            Projectile.aiStyle = -1;                   // AI 样式：-1 表示不使用原版预设 AI，由自己写
            Projectile.timeLeft = 450;                 // 存活时间（帧），450 帧 = 7.5 秒
            Projectile.extraUpdates = 1;               // 额外更新次数，1 表示每帧更新 2 次（速度翻倍的感觉）

            // 这里是重点：
            ProjectileID.Sets.TrailingMode[Projectile.type] = 0;      // 拖尾记录模式：0 = 只记录位置
            ProjectileID.Sets.TrailCacheLength[Projectile.type] = 30; // 拖尾缓存长度：记录最近 30 个位置
        }
        private Vector2[] oldPosi = new Vector2[16];
        private int frameTimer = 0;

        public override void AI()
        {
            frameTimer++;

            if (frameTimer % 2 == 0)  // 每两帧记录一次
            {
                for (int i = oldPosi.Length - 1; i > 0; i--)
                {
                    oldPosi[i] = oldPosi[i - 1];
                }
                oldPosi[0] = Projectile.Center;
            }

            // 弹幕贴图朝上时的旋转角度（如果贴图朝向不同，调整这里）
            Projectile.rotation = Projectile.velocity.ToRotation() + MathHelper.PiOver2;

            Projectile.velocity.Y += .1f;// 水平下落
            Projectile.velocity.X *= 0.995f; // 水平减速
            // 限制最大下落速度，避免砸得太快
            if (Projectile.velocity.Y > 16f)
            {
                Projectile.velocity.Y = 16f;
            }
            // if (frameTimer % 3 == 0)  // 每两帧记录一次
            {
                Dust dust = Dust.NewDustDirect(
                   Projectile.position,              // 1. 生成位置
                   Projectile.width,                 // 2. 生成区域宽度
                   Projectile.height,                // 3. 生成区域高度
                   DustID.Torch,                     // 4. 粒子类型 (火焰)
                   0f,                               // 5. 水平初速度
                   0f,                               // 6. 垂直初速度
                   100,                              // 7. 透明度 (Alpha)
                   default(Color),                   // 8. 颜色 (Color)
                   2f                                // 9. 大小缩放 (Scale)
                   );

                // 粒子特效不受重力
                dust.noGravity = true;
                // 让粒子默认的运动速度归零
                dust.velocity *= 5;
                // 让粒子始终处于弹幕的中心位置
                dust.position = oldPosi[2];
            }
        }

        public override bool PreDraw(Player player, ref Color lightColor)
        {
            Texture2D tex = ModContent.Request<Texture2D>(Texture).Value;

            for (int i = oldPosi.Length - 1; i > 0; i--)
            {
                if (oldPosi[i] != Vector2.Zero)
                {
                    //试试修改这里的0.05f与0.02f，想想它们意味着什么
                    Main.spriteBatch.Draw(
                        tex,
                        oldPosi[i] - Main.screenPosition,
                        null,
                        Color.White * (1f - 0.05f * i),          // 透明度递减
                        (oldPosi[i - 1] - oldPosi[i]).ToRotation() + MathHelper.PiOver2, //如果贴图不在你所期望的方向上，你知道要做什么的
                        tex.Size() / 2f,                          // 原点：贴图中心
                        1f * (1f - 0.02f * i),                    // 缩放递减
                        SpriteEffects.None,
                        0f);
                }
            }
            return false;
        }
    }
}
```
