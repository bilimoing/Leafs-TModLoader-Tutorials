# 什么是绘制

绘制只负责纯粹的视觉效果，将你所做的内容以画面呈现出来

但是怎么让电脑知道我们想呈现哪些内容呢？让我们想想至少需要提供哪些信息

首先得知道用哪张图，再然后还得给定这张图的位置，最基础的需求就是这样了吧

随着我们的需求不断复杂，我们可能并不满足单纯指定纹理和位置，我们可能会希望传入颜色参数，可能会希望裁切下图中的一小块而不用整张图，可能会希望能够旋转一下，或者水平垂直翻转等等

我们将在下一篇教程 Draw各重载详解 中逐一介绍SpriteBatch类提供的绘制重载

除了怎么画上一张图的问题，还有新画上去的图和原先画面内容怎么混合的问题、采样问题遮挡问题等等，我们将在下下篇教程中逐一介绍SpriteBatch类的Begin参数中各参数的含义与用法

再然后，如果我需要几张图合成得到最终效果呢？如果我希望中间用一个专用的程序处理颜色呢？如果我想要自己控制形状而不局限在矩形呢？等等等等

这些也都会再后续的教程中逐渐补充讲解

# 从弹幕绘制开始吧

泰拉模组内容开发最兼顾简单和自由的应该就是弹幕了，而且弹幕又是一个很需要通过自行处理绘制以提升表现力的内容，因此我们将从弹幕开始

在一个ModProjectile类中，重写`PreDraw`和`PostDraw`两个函数

它们分别发生在默认绘制前和默认绘制后

前者允许你禁用默认绘制并进行自定义的绘制逻辑，或者给默认绘制的颜色参数传参

后者则是在默认绘制之后进行补充绘制

以下是`ModProjectile`类中两个函数的定义

```csharp
public virtual bool PreDraw(ref Color lightColor)
{
    return true;
}

public virtual void PostDraw(Color lightColor)
{
}
```

PreDraw的返回值类型是bool，如果返回true就会阻止原版绘制，但是不论是true还是false都会执行后续的PostDraw

一般如果PreDraw返回了false就不需要再使用PostDraw了，我们可以在PreDraw里完成所有的工作

## 坐标系？

在正式开始绘制之前我们需要先梳理下泰拉这边都有哪些坐标，搞清楚坐标关系了之后我们才好下手，不然很容易遇见"没效果"的问题

游戏大多数内容部分，像玩家的位置、弹幕的位置、NPC的位置等等，它们都用的是**世界坐标**，从世界的左上角开始，往右是x正方向，往下是y正方向，如果你的缩放系数是100%，那就是一个像素对应世界坐标的一个单位

而物块则使用的是**物块坐标**，物块坐标即这个物块在物块网格中的整数格点位置，一个物块占据16x16的世界坐标空间，也就是说我们将世界坐标除以16再向下取整就能得到物块坐标

而我们今天要讨论的是**屏幕坐标**

在缩放系数为100%的时候，画面左上角的世界坐标称为屏幕世界坐标，将世界坐标减去屏幕世界坐标得到的就是屏幕坐标

大概就像下面这样

```csharp
// 弹幕中心的屏幕坐标  // 弹幕中心的世界坐标    // 屏幕左上角的世界坐标
Vector2 center =    Projectile.Center    - Main.screenPosition
```

在此基础上修改缩放系数，画面内容会以屏幕内容为中心进行缩放，此时你看到的画面的左上角的坐标并非"屏幕世界坐标"，但是这个缩放并不影响我们绘制阶段的坐标计算，用我上面给出的屏幕坐标公式就好啦

## 获取精灵图

下一个问题是我们怎么从模组中拿到我们想要的精灵图呢？

对于弹幕自身配套的那个贴图，可以用`TextureAssets.Projectile[type]`获取

而其它的贴图，用ModContent.Request或者ModAsset.Request获取

像这样

```csharp
// 假设你的模组是这样的
// ModSource/MyMod
//    |- Assets/Image/MyImage.png
//    |- Content/Projectiles/MyProjectile.png
// 现在我们需要获取到MyImage.png和MyProjectile.png在弹幕绘制的时候使用

// 声明一个静态属性，加载的时候Request以给后续复用
public static Asset<Texture2D> MyImage { get; private set; }

// Load的时候如果不是服务端就加载
public override void Load()
{
    if(!Main.dedServ) 
    {
        // 这里不需要写后缀名
        MyImage = ModContent.Request<Texture2D>("MyMod/Assets/Image/MyImage");
        
        // 有自己的Mod实例的话可以用这个版本
        // MyImage = Mod.Assets.Request<Texture2D>("Assets/Image/MyImage");
    }
}

public override void Unload()
{
    MyImage = null;
}
```

这里Request请求得到的是`Asset<Texture2D>`，而我们实际要使用的精灵图是内部的Texture2D类型的Value属性，请求资源默认采用异步加载，因此不能当场拿了Value然后拍屁股走人

等到后续PreDraw的时候大概率已经加载好资源了，这时再通过Value拿到Texture2D就没问题了

## 绘制

现在重写`PreDraw`函数，然后开始绘制吧！

重写默认的实现是这样的

```csharp
public override bool PreDraw(ref Color lightColor)
{
    return base.PreDraw(ref lightColor);
}
```

在弹幕的PreDraw函数里，我们一般使用`Main.EntitySpriteDraw`函数进行绘制，而在别的很多地方，以及`EntitySpriteDraw`内部，都是用一个叫`SpriteBatch`的类进行绘制

使用这个函数进行绘制的宠物和召唤物弹幕会自动被应用上染料效果，对其它弹幕而言和直接使用Main.spriteBatch.Draw其实没什么区别

```csharp
public override bool PreDraw(ref Color lightColor)
{
    // 如果想用弹幕自身的那个图而非MyImage就用
    // TextureAssets.Projectile[Type].value
    // 要获取别的原版弹幕的贴图就把Type换成原版弹幕的ID就行了
    Main.EntitySpriteDraw(
        texture: MyImage.Value,
        position: Projectile.Center - Main.screenPosition,
        sourceRectangle: null,
        color: Color.White,
        rotation: Projectile.rotation,
        origin: MyImage.Value.Size() * 0.5f,
        scale: 1f,
        spriteEffect: SpriteEffects.None,
        worthless: 0
        );
    return false;
}
```

第一个参数就是我们要绘制的精灵图啦

第二个是屏幕坐标，前面已经讲过了

第三个是精灵图上的裁切矩形，有时候我们需要裁切一部分下来绘制，传null表示使用整张图

第四个是颜色，会和原先精灵图的像素颜色用乘法混合，比如红色分量部分，一个是255，一个是51，这里会先归一化到1，前者变成1.0，后者变成0.2，再进行相乘得到0.2，最终显示出来就是51

第五个是旋转角度，逆时针旋转，弧度制

第六个是裁切矩形的锚点，矩形锚点的位置会映射到屏幕坐标给定的位置，旋转也是以它为中心进行旋转，比如上面的代码中就是以图像的中心为旋转中心，把它放在给定屏幕坐标的位置

第七个是缩放系数，1就是精灵图自身的大小

第八个是水平、垂直翻转, None表示不翻转

第九个在EntitySpriteDraw中被称为worthless，在泰拉的绘制中这个值确实用不到，实际上是在传递深度信息，后续Draw各重载及Begin参数详解中会进一步解释

# 常用绘制内容写法

## 拖影绘制

在弹幕中心的绘制上面教了，那如果我想绘制弹幕拖影该如何实现呢？这里其实有几种实现思路

拖影和普通的相比其实无非就是用了之前的坐标和旋转，以及透明度需要调整下

```csharp
Main.EntitySpriteDraw(
    texture: MyImage.Value,
    position: xxxx - Main.screenPosition, // 这里要换成旧坐标
    sourceRectangle: null,
    color: xxxxx, // 这里要做个透明度修改
    rotation: xxxxxx, // 还有旋转角度也要换成旧的！
    origin: MyImage.Value.Size() * 0.5f,
    scale: 1f,
    spriteEffect: xxxxxxx, // 还有朝向万一也改变了呢
    worthless: 0
    );
```

弹幕其实提供了现成的坐标记录的数组！只要设置一下拖尾模式就好啦

```csharp
public override void SetStaticDefaults() 
{
    // 设置拖尾模式
    ProjectileID.Sets.TrailingMode[Type] = 2;
    
    // 设置缓存长度
    ProjectileID.Sets.TrailCacheLength[Type] = 30;
}
```

拖尾模式默认值为-1，表示不使用拖尾缓存，以下是不同模式的释意

|**模式ID**|**效果**|
|---|---|
|0|仅记录position (在Projectile.OldPos数组中)|
|1|仅在frameCounter为0或未记录过的时候更新记录position,TML的注释建议不要用|
|2|记录position rotation spriteDirection，后两者分别对应oldRot和oldSpriteDirection|
|3|记录position rotation spriteDirection, 但是带有一定插值效果，坐标而言有一个措施更新旧坐标从而让它在离新坐标过远的时候靠近一段距离，角度完全由坐标差值计算|
|4|记录position rotation spriteDirection，但是position会根据所属玩家的移动而更新，表现上更像是记录了相对坐标|
|5|记录position rotation spriteDirection，但是rotation不是弹幕的旋转角度而是速度矢量的朝向角|


这里OldXXX都是索引越小越新，0就是上一次更新后的值

而绘制顺序是越后绘制的越在上面(至少默认而言是这样，采用不同排序模式可能行为不一样)

因此我们要从大的索引开始循环，这样才能保证越新的在越上层

最后就是这样：

```csharp
public override bool PreDraw(ref Color lightColor)
{
    Texture2D texture = TextureAsset.Projectile[Type];
    Vector2 origin = texture.Size() * 0.5f;

    // 因为OldPos记录的是弹幕左上角位置，这里保存一个offset备用
    Vector2 offset = new Vector2(Projectile.width, Projectile.height) * 0.5;

    int length = Projectile.oldPos.Length;

    // 保存一个浮点数版本的备用
    float lengthf = (float)length;

    // 从旧到新绘制拖尾
    for (int n = length - 1; n >= 0; n--)
    {
        // 插值因子，这里只用来影响透明度
        float factor = 1 - n / lengthf;
        factor *= 0.5f;
        Main.EntitySpriteDraw(
            texture,
            Projectile.OldPos[n] + offset - Main.screenPosition,
            null,
            lightColor * factor,
            Projectile.OldRot[n],
            origin,
            1f,
            Projectile.oldSpriteDirection[n] == -1
            ? SpriteEffects.FlipHorizontally
            : SpriteEffects.None,
            0
            );
    }

    // 最后绘制弹幕本体
    Main.EntitySpriteDraw(
        texture,
        Projectile.Center - Main.screenPosition,
        null,
        lightColor,
        Projectile.rotation,
        origin,
        1f,
        Projectile.spriteDirection == -1
        ? SpriteEffects.FlipHorizontally
        : SpriteEffects.None,
        0
        );
    return false;
}
```

## 发光效果绘制

我们也许会觉得原先的弹幕太单调了，要是能加上一圈高亮光晕就很酷炫了！

思路也很简单，给一个比较小的坐标偏移，然后再半透明绘制，叠加在已有的内容上就可以啦

```csharp
public override bool PreDraw(ref Color lightColor)
{
    Texture2D texture = TextureAsset.Projectile[Type];

    // 自行整个高亮部分的贴图，或者你要直接用上面的texture也行
    Texture2D glowTexture = Glow.Value;

    Vector2 origin = texture.Size() * 0.5f;

    SpriteEffect spriteEffect =
        Projectile.spriteDirection == -1
            ? SpriteEffects.FlipHorizontally
            : SpriteEffects.None;

    // 先绘制弹幕本体
    Main.EntitySpriteDraw(
        texture,
        Projectile.Center - Main.screenPosition,
        null,
        lightColor,
        Projectile.rotation,
        origin,
        1f,
        spriteEffect,
        0
        );

    // 盖在上面的光晕效果！
    const int MaxGlow = 4;
    float factor = 1f / MaxGlow;
    float radStep = MathHelper.TwoPi / MaxGlow;
    for (int n = 0; n < MaxGlow; n++)
    {
        Main.EntitySpriteDraw(
            glowTexture,
            Projectile.Center
            + (radStep * n).ToRotationVector2() * 2
            - Main.screenPosition,
            null,
            Color.White with { A = 0 } * factor,
            Projectile.rotation,
            origin,
            1f,
            spriteEffect,
            0
            );
    }
    return false;
}
```

这里用ToRotationVector2将旋转角转为了相应方向的单位向量，再乘上2表示长度为2的坐标偏移

然后下面Color.White with {A = 0}的 with {A = 0}看着也许有些神奇，这个会在后续Begin参数详解中的BlendState给出更详细的解释，目前你只需要知道用with {A = 0}之后就神奇地能够将新画上的颜色和之前已有的直接相加了

## 帧图绘制

目前为止上面讲的一大堆都是使用完整图的绘制方式，但是既然叫精灵绘制，肯定是使用精灵图，也就是将动画不同帧整合在一张图的绘制，这时我们就需要用上裁切矩形了

这里原版为我们准备了一个很方便的拓展函数来获取裁切矩形：Frame函数

第一个参数表示横向的总帧数，第二个表示纵向

第三第四个表示现在横向和纵向分别采用第几帧

第五第六个是裁切矩形的坐标偏移

这个函数的假设是你的精灵图每一帧都是一样的尺寸大小，

所以会根据你传入的总帧数将精灵图进行等分

然后再根据当前采用帧索引来确定裁切矩形(0为第一帧)

最后再根据你的需求看看要不要给矩形加上个坐标偏移，一般用不上

比如下面的示例就是给一个总共有横向1帧，纵向10帧的精灵图使用的

```csharp
public override bool PreDraw(ref Color lightColor)
{
    Texture2D texture = TextureAsset.Projectile[Type];
    Rectangle frame = texture.Frame(1, 10, 0, Projectile.frame, 0, 0);
    Vector2 origin = frame.Size() * 0.5f;

    SpriteEffect spriteEffect =
        Projectile.spriteDirection == -1
            ? SpriteEffects.FlipHorizontally
            : SpriteEffects.None;

    Main.EntitySpriteDraw(
        texture,
        Projectile.Center - Main.screenPosition,
        frame,
        lightColor,
        Projectile.rotation,
        origin,
        1f,
        spriteEffect,
        0
        );
    return false;
}
```

而Projectile.frame的更新就在`AI`函数里自己实现吧，比如这样：

```csharp
public override void AI()
{
    Projectile.frameCounter++;
    if (Projectile.frameCounter >= 3)
    {
        Projectile.frameCounter = 0;
        Projectile.frame++;
        Projectile.frame %= 10;
    }

    /*
     *   其它更新逻辑
     */
}
```
