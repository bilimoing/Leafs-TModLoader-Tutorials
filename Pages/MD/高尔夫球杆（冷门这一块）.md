接下来让我看看具体怎么来实现一个高尔夫球杆。

```csharp
public override void SetStaticDefaults()
{
  ItemID.Sets.IsAGolfClub[Type] = true;
}
```

这是一个很重要的东西，让游戏把你的物品当作一个高尔夫球杆！！！在 `SetStaticDefaults`** **中来写它。

现在说正题，我们要创建一个高尔夫球杆，想必也知道用哪个了吧？

```csharp
public override void SetDefaults()
{          
  Item.DefaultToGolfClub(20, 20); // 这样就可以直接让他拥有高尔夫球杆的属性
}
```

如果你要直接继承某个高尔夫球杆一样的属性的话，你可以直接用 **`Item.CloneDefaults();` **来直接继承某个高尔夫球杆的完整属性。

那么问题来了，我不想和原版的高尔夫球杆一样，想写一个自己的高尔夫球杆怎么办？那么下面这个就是当前教程的重中之重了！！！

在1.4.4版本中，我们需要On或者IL去将我们的高尔夫的属性添加进去，但是在1.4.5版本添加了下面这么一个东西。

```csharp
public override GolfHelper.ClubProperties? GetGolfClubProperties()
{
   return new GolfHelper.ClubProperties(
        minimumStrength: new Vector2(0.25f, 0.25f),
        maximumStrength: new Vector2(1.5f, 0.65f),
        roughLandResistance: 0f
    );
}
```

这是可以让你可以自定义高尔夫球杆的方法，可以用这个来区分各种高尔夫球杆的种类。

```csharp
public static ClubProperties GetClubProperties(short itemId)
{
  if (ItemLoader.GetGolfClubProperties(itemId, out ClubProperties moddedProperties))
     return moddedProperties;

        Vector2 vector = new Vector2(0.25f, 0.25f);
        switch (itemId) {
            case 4039:
                return new ClubProperties(vector, Vector2.One, 0f);
            case 4092:
                return new ClubProperties(Vector2.Zero, vector, 0f);
            case 4093:
                return new ClubProperties(vector, new Vector2(0.65f, 1.5f), 1f);
            case 4094:
                return new ClubProperties(vector, new Vector2(1.5f, 0.65f), 0f);
            case 4587:
                return new ClubProperties(vector, Vector2.One, 0f);
            case 4588:
                return new ClubProperties(Vector2.Zero, vector, 0f);
            case 4589:
                return new ClubProperties(vector, new Vector2(0.65f, 1.5f), 1f);
            case 4590:
                return new ClubProperties(vector, new Vector2(1.5f, 0.65f), 0f);
            case 4591:
                return new ClubProperties(vector, Vector2.One, 0f);
            case 4592:
                return new ClubProperties(Vector2.Zero, vector, 0f);
            case 4593:
                return new ClubProperties(vector, new Vector2(0.65f, 1.5f), 1f);
            case 4594:
                return new ClubProperties(vector, new Vector2(1.5f, 0.65f), 0f);
            case 4595:
                return new ClubProperties(vector, Vector2.One, 0f);
            case 4596:
                return new ClubProperties(Vector2.Zero, vector, 0f);
            case 4597:
                return new ClubProperties(vector, new Vector2(0.65f, 1.5f), 1f);
            case 4598:
                return new ClubProperties(vector, new Vector2(1.5f, 0.65f), 0f);
            default:
                return default(ClubProperties);
  }
}
```

这是原版判定所有高尔夫球杆的方法。

- `Vector2.Zero` 作为**minimumStrength（最小力度）** → **推杆**

- `Vector2.One`(1,1) 最大力度 → **铁杆**

- `new Vector2(0.25f,0.25f)`基础最小力度 + `(0.65f,1.5f)`最大力度 → **挖起杆**

- `new Vector2(0.25f,0.25f)`基础最小力度 + `(1.5f,0.65f)`最大力度 → **木杆**

  通过填写不同的数值来决定高尔夫球杆的种类。

  当然你也看见原版有很多高尔夫球杆，这些球杆只是品质之间的不同，实际上参数没有区别。

  ![图片](images/tutorials/abf2a5621f5cca143509831e.png)

  

  现在你写完了，你现在想要你的高尔夫球杆可以获取，在原版中是高尔夫球杆是由高尔夫球手售卖的，而高品质的球杆需要高尔夫球达到一定的分数。如果你想让你的高尔夫球杆也这样获取，那么需要在`GlobalNPC`中来编写。虽然现在貌似没有讲这一段？（至少我还没看见）

  创建一个cs文件，然后继承`GlobalNPC`，然后在里面写上

  ```csharp
  public override void ModifyShop(NPCShop shop) // 修改NPC的商店
  {
     if (shop.NpcType == NPCID.Golfer) // 判定为高尔夫球手
     {
       shop.Add<ExampleGolfClub>(Condition.GolfScoreOver(250)); // 超过对应分数就会售卖
     }
  }
  ```

  这样你的高尔夫球杆就被装进对应的NPC商店里面了。（虽然好像没这个教程呢，催更叶子！！！）
