我们看向这些绿油油，前面带着两个斜杠的文字。它叫**注释**，是代码中写给**人类**看的内容，**编译器**会完全忽略它们。**注释**不会影响代码的运行，它负责给代码的读者提供额外的信息。



C\#中的注释有两种写法

**1单行注释**

![图片](images/tutorials/4ec752d09bf672732cd06253.png)

```csharp
// 这是一条注释
```

可以对某一行代码做简短说明，写在代码的同一行或上一行

**2多行注释**  

![图片](images/tutorials/4921b304f2430fefad0918b8.png)

```csharp
/* 
这是 
多行注释 
*/
```

可以对一段代码做说明，或者临时注释掉一大块代码用于调试

![图片](images/tutorials/dc58a80f14ee1e6413bab9a3.png)

现在我们将目光放到**SetDefaults()** 方法，

这个方法在物品的实例被创建时会执行一次（游戏启动时加载模组，玩家通过合成获得物品，代码里 new 出一个）它负责给物品设定**初始的基础属性**



简单来说，就是物品默认的属性。

比如 **攻击力、大小、使用速度、稀有度**等等全都在这里设置。

游戏里无论生成多少这个物品，都会按照这我们写的这份模板来初始化它。



现在，我们来逐行解读里面的内容

**damage** 

代表着基础攻击力，类型为正整数，泰拉瑞亚原版剑通常在 15\~200 之间。

**DamageType** 

代表着伤害类型，有 Melee（近战）、Ranged（远程）、Magic（魔法）、Summon（召唤）等可选。

**width / height** 

代表着物品尺寸，单位是像素，会影响物品掉落在地面上的拾取范围。

**useTime** 

代表着使用间隔，数值越小攻速越快。游戏以帧为单位（60帧=1秒），10 表示每秒 6 次，30 表示每秒 2 次。

**useAnimation** 

代表着挥动动画时长，通常和 useTime 保持一致，不一致时会产生特殊效果。

**useStyle** 

代表着使用动作，有 Swing（挥动）、HoldUp（举起）、Thrust（突刺）等类型。

**knockBack** 

代表着击退力，数值越高敌人被击退得越远，0 表示无击退效果。

**value** 

代表着出售价格，可以用 Item.buyPrice(gold: 1) 或直接写整数（单位为铜币数，如 10000）。

**rare** 

代表着稀有度，有 Blue（蓝）、Green（绿）、Orange（橙）、Red（红）等，决定物品名字的颜色。

**UseSound** 

代表着使用音效，有 Item1（剑挥动）、Item2（刀挥动）等可选。

**autoReuse** 

代表着自动连击，true 表示按住不放持续攻击，false 表示每次使用需要重新点击。

```csharp
Item.damage = 50;              // 攻击力：50点
Item.DamageType = DamageClass.Melee; // 伤害类型：近战（受近战加成影响）
Item.width = 40;               // 物品的宽度（像素，影响拾取范围和碰撞判定）
Item.height = 40;              // 物品的高度（像素）
Item.useTime = 20;             // 每次攻击耗时（帧数，数值越小攻速越快）
Item.useAnimation = 20;        // 每次攻击的动画时长（帧数，通常与useTime保持一致）
Item.useStyle = ItemUseStyleID.Swing; // 使用方式：挥动（剑类标准动作）
Item.knockBack = 6;            // 击退力（数值越大击退越远）
Item.value = Item.buyPrice(silver: 1); // 物品价值（1银币，也可以直接用int值）
Item.rare = ItemRarityID.Blue; // 稀有度：蓝色（对应游戏里的颜色等级）
Item.UseSound = SoundID.Item1; // 使用音效：Item1（剑挥动的声音）
Item.autoReuse = true;         // 是否自动连击（true=按住鼠标持续攻击）
```

接下来我们讲一下**AddRecipes()** 聪明的同学可能已经发现了一些规律，这个方法内部的参数和我们模板剑的合成表完全一致。是的，这个方法就是用来管理物品要怎么合成的。

惯例，我们来逐行解读



**CreateRecipe()**  新建一个配方对象，准备定义它

**AddIngredient(物品ID, 数量)**  添加合成所需的材料，数量不写默认为1

**AddTile(站台ID)**  合成时需要站在什么工作台旁边（可选）

**Register()**  把这个配方注册到游戏里，让它可以被使用

```csharp
// 简单配方：10个土块直接合成
recipe.AddIngredient(ItemID.DirtBlock, 10);

// 多种材料：需要铁锭+木材
recipe.AddIngredient(ItemID.IronBar, 5);
recipe.AddIngredient(ItemID.Wood, 20);

// 不需要工作台（在背包里就能合成）
// 不写 AddTile 就行了

// 需要在铁砧旁边
recipe.AddTile(TileID.Anvils);

// 需要两种工作台条件（比如站在桌子+椅子旁边）
recipe.AddTile(TileID.Tables);
recipe.AddTile(TileID.Chairs);
```

更多的例子.... 



注意我这里的ItemID.XXX，这些其实就是物品的ID，如果你选择右键，速浏定义，你的编译器窗口会弹出源码里DirtBlock = 2; 的部分



知道了土块ID是2，那么我可以写**recipe.AddIngredient(2, 10);**

也可以写 **recipe.AddIngredient(ItemID.DirtBlock, 10);**



这里用**ItemID.DirtBlock**和**TileID.WorkBenches**是命名常量的写法（物品ID和方块ID本质上都是数字）如果你暂时记不住这些名字，先用数字也可以，但推荐用ID，因为过两天回来看代码的时候，**ItemID.DirtBlock**比 2 好认一万倍。
