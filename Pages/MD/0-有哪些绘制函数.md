# 前言

这篇笔记旨在列出tModLoader提供的**大多数**绘制API(至少是笔者所知的)，以及相关使用注意事项

这篇不适合作为教程直接阅读，但是可以作为用来随时查阅的工具手册，请先阅读后续几篇，再回到这里找到你感兴趣的绘制入口，开始你的绘制之旅！

tModLoader中有很多重写函数以Pre Post前缀成对出现，在这里的语境下是这样的含义：

Pre表示发生在默认绘制实现之前，可用于禁用默认绘制(return false)，或者修改一些默认实现用到的参数

Post发生在默认绘制之后，一般用于在默认绘制上加额外绘制，如果已经用了Pre一般可以不需要Post(直接在Pre里写完所有绘制实现)

本篇教程相应的使用例可以在[这里](https://github.com/LogSpiral/TmodDrawingAPIsExample)找到

# 物品(Item)

- PreDrawInWorld

- PostDrawInWorld

  修改物品作为掉落物时在世界内的绘制行为

  提供如下参数：

  spriteBatch

  lightColor: 物品受到的光照颜色

  alphaColor: 物品的光照颜色经过物品自身追加处理后的颜色，默认绘制采用alphaColor

  rotation: 逆时针旋转角度

  scale: 缩放系数

  whoAmI: 物品实例在Main.item数组中的索引

  其中对于1449的GlobalItem还提供了Item实例以直接获取物品位置

  对于1458，GlobalItem和ModItem均提供了WorldItem实例以直接获取物品位置

- PreDrawInInventory

- PostDrawInInventory

  修改物品在背包格子内的绘制行为

  提供如下参数：

  spriteBatch

  position: 背包内绘制的位置

  frame: 裁切帧矩形

  drawColor: 绘制物品使用的颜色

  itemColor: 某些物品特有的神必二次着色

  origin: 绘制锚点

  scale: 缩放系数

  对于GlobalItem，还提供了Item实例，对于ModItem可以直接用this.Item以获取到Item实例

- PreModifyItemDraw

- PostModifyItemDraw

  修改物品使用期间的绘制行为

  提供如下参数：

  drawInfo: 用来修改一些绘制信息，甚至提交额外的绘制缓存也不是不行(x)

  drawData: 当次(将/已经)提交的绘制缓存信息

  coloredDrawData: 和drawData类似，默认给Color字段不为Color.Transparent的物品用

  glowmaskDrawData: 和drawData类似，默认给有高亮层的物品用

  **这里不能直接用SpriteBatch进行绘制，而是创建DrawData然后添加到DrawInfo的缓存里**

- PreDrawTooltip

- PostDrawTooltip

  修改物品描述的绘制行为

  提供如下参数：

  lines: 所有描述行，只读

  如果是Pre还会提供x和y用来修改绘制位置

- PreDrawTooltipLine

- PostDrawTooltipLine

  修改物品单行描述的绘制行为

  提供如下参数：

  line: 当前描述行

  如果是Pre还会提供y用来修改下一行的偏移位置

# 弹幕(Projectile)

- PreDrawExtras

  用来控制是否进行一些弹幕背后的"额外绘制"

  主要给原版弹幕使用，比如悠悠球和鱼竿浮标的线

  也可以用来给弹幕背后插入些绘制内容

  不提供绘制参数，GlobalProjectile里提供Projectile实例参数

- PreDraw

- PostDraw

  修改弹幕的绘制行为

  提供如下参数

  lightColor: 弹幕的光照颜色

  在1458中还提供了弹幕所属玩家的实例player

  在这里一般不用SpriteBatch进行绘制，而是用Main.EntitySpriteDraw

  如果非要用不可，可以用Main.spriteBatch实例

# NPC

- DrawEffects

  用来修改绘制颜色、生成粒子效果等(虽然我个人觉得在AI函数生成也许更合适)

  在PreDraw之前执行，理论上也可以用Main.spriteBatch进行绘制，但是没必要

- PreDraw

- PostDraw

  修改NPC的绘制行为

  提供如下参数

  spriteBacth

  screenPos: 屏幕位置

  drawColor: 绘制颜色

- DrawHealthBar

  控制是否绘制血条

  返回null表示采用原版行为，false表示不绘制，true表示采用修改后的position参数绘制血条

  也可以用来自定义血条绘制实现

  提供如下参数

  hbPosition: 控制血条绘制的位置模式

  scale: 血条的缩放系数

  position: 血条的位置，注意要让修改生效需要return true

- DrawTownAttackGun

  修改城镇NPC的枪械攻击动画

  提供如下参数

  item: 物品精灵图，可修改

  itemFrame: 裁切帧，可修改

  scale: 缩放系数，可修改

  horizontalHoldoutOffset: 水平偏移量，可修改

- DrawTownAttackSwing

  修改城镇NPC的挥动攻击动画

  提供如下参数

  item: 物品精灵图，可修改

  itemFrame: 裁切帧，可修改

  itemSize: 物品大小，可修改

  scale: 缩放系数，可修改

  offset: 位置偏移，可修改

# UI

- Draw

  修改UI元素的绘制控制行为

  默认实现下会触发OnDraw事件，后续先执行DrawSelf绘制自身，再执行DrawChildren绘制子元素，一般不会去重写这个函数

- DrawSelf

  UI元素自身的绘制实现

  提供spriteBatch参数

  **UI相关的绘制主要重写DrawSelf函数**

- DrawChildren

  UI元素绘制子元素的实现

  默认遍历所有子元素执行它们的Draw函数

# 物块(Tile)

- PreDraw

- PostDraw

  *注：这两个属于BlockType的函数，即Tile和Wall共有，查引用请到相应ModBlockType和GlobalBlockType查找*

  修改单个物块绘制前后的行为

  提供如下参数

  i 物块横坐标

  j 物块纵坐标

  type 物块ID(仅Global)

  spriteBatch

- DrawEffects

  修改单个物块的绘制效果(颜色等) 或者添加特殊绘制的注册点

  执行顺序上在PreDraw之后，PostDraw之前，理论上也可SpriteBatch.Draw

  提供如下参数

  i 物块横坐标

  j 物块纵坐标

  type 物块ID(仅Global)

  spriteBatch

  drawData，可修改

- SpecialDraw

  用于进行独立于一般物块绘制顺序的特殊绘制，比如晶塔的水晶、物品框的物品等

  需要在DrawEffects使用Main.instance.TilesRenderer.AddSpecialLegacyPoint添加特殊点才行

  提供如下参数

  i 注册点横坐标

  j 注册点纵坐标

  type 物块ID(仅Global)

  spriteBatch

- PreDrawPlacementPreview

  用于在原版放置预览下方图层添加预览内容，或者修改原版放置预览，或者禁用原版预览

  提供如下参数

  i 物块横坐标

  j 物块纵坐标

  type 物块ID(仅Global)

  spriteBatch

  frame 裁切帧，可修改

  position 绘制位置，可修改

  color 颜色，可修改

  validPlacement 当前是否是正确的放置

  spriteEffect 水平、垂直翻转，可修改

- PostDrawPlacementPreview

  用于在原版放置预览上方图层添加预览内容

  提供如下参数

  i 物块横坐标

  j 物块纵坐标

  type 物块ID(仅Global)

  spriteBatch

  frame 裁切帧

  position 绘制位置

  color 颜色

  validPlacement 当前是否是正确的放置

  spriteEffect 水平、垂直翻转

# 玩家(Player)

玩家因为绘制层组成相当复杂，需要使用PlayerDrawLayer来插入绘制层

PlayerDrawLayer

- Draw

  进行当前层的玩家绘制

  绘制所需的信息(玩家、颜色等)均由drawInfo提供

  此外，也不应直接在这里使用spriteBatch，而是向drawInfo的DrawDataCache添加DrawData，用法和spriteBatch的Draw基本可以认为一致

  PlayerDrawLayer.Transformation

- PreDraw

- PostDraw

  设计上来讲它们是成对出现使用，用来临时修改DrawInfo和还原

  但是你也可以在这里添加DrawData

  在ModPlayer中还提供了修改绘制层顺序、修改绘制信息、隐藏绘制层等函数，因为不算直接的绘制接口这里先略过了

  最后还有一个ModPlayer的DrawPlayer

  设计上是让你多次调用Main.PlayerRenderer.DrawPlayer来实现自定义拖影效果

  但是也可以自行SpriteBatch.Draw来添加绘制

# 模组系统(ModSystem)

- PostDrawInterface

  在其它界面层上、鼠标和文本界面层下添加绘制界面内容

  目前**不建议使用**这个函数，而是用ModifyInterfaceLayers

  提供spriteBatch

- ModifyInterfaceLayers

  用来插入一个界面绘制层

  提供当前所有绘制层所在的列表，用于自行insert一些GameInterfaceLayer实例

  GameInterfaceLayer实例创建时需要指定你的绘制内容以及你的绘制层缩放类型

  传入的委托不提供任何参数，需要返回bool，return false表示禁用后续绘制层

- PreDrawMapIconOverlay

  用于控制某个地图图标叠加层是否进行绘制

  理论上也可用于直接绘制，但是不在设计范围内

- PostDrawTiles

  在物块层上方添加绘制内容，需要自行Begin和End

  不提供任何参数，需要使用Main.spriteBatch

# 云(Cloud)

需要继承ModCloud类

- Draw

  提供参数如下

  Cloud 云实例

  cloudIndex 云实例的索引

# 坐骑(Mount)

- Draw

  控制坐骑的绘制行为，只有ModMount中有

  提供参数如下

  playerDrawData 玩家绘制数据缓存

  drawType 绘制类型，0表示背部，1表示背部额外内容，2表示前部，3表示前部额外内容

  drawPlayer 坐骑上的玩家实例

  texture 坐骑采用的精灵图，可修改

  glowTexture 坐骑采用的高亮精灵图，可修改

  drawPosition 坐骑绘制位置，可修改

  frame 裁切帧，可修改

  drawColor 绘制颜色，可修改

  glowColor 高亮颜色，可修改

  rotation 旋转角度，可修改

  spriteEffects 翻转效果，可修改

  drawOrigin 绘制锚点，可修改

  drawScale 缩放系数，可修改

  shadow 拖影透明度系数
