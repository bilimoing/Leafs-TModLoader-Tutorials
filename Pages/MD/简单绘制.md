## 简单绘制

在前面几节教程中，我们的所有内容都是“图片长什么样，游戏就画成什么样”。贴图朝上画，物体就朝上显示；贴图多大，就显示多大。碰撞体积和贴图之间的关系，完全由你画图时就定死了。



但有时候，我们想要的更多。比如：

- 想在原有图片的基础上画一些额外的贴图

- 想画多张图叠加，做出光晕，拖尾的效果

- 想要npc自己显示一些文字，做出在世界上发言的效果

  

  这时候，默认的绘制方式就不够用了。我们需要**自己接管绘制，**用代码告诉游戏：“这个东西怎么画，由我来决定。”

### 世界坐标与屏幕坐标

在讲绘制之前，必须先搞清楚绘制里的一个核心概念：**世界坐标和屏幕坐标**

它们描述的是同一个东西，但参照物不同。我们先来看一张图，尝试理解一下它们的区别。

![图片](http://www.kdocs.cn/api/v3/office/copy/YWtmU0lpSzZ2cjlhNG92OXlwUWRwWTBnRCtNYmdpR3FMMjRMTkFxUDZwcmlUelN5V0huNkgwUTBwZlA1Y0xyR0xNc1RsL2ZLSUhBZTJEaSs0R3FJSXp5WkV6SHNyWFZoYkUvRmU2L2RDbHdNYkoyZmZ6OThvN1piWG1HOHdIV2MwcWYrMlJ5WEVJZnJ4SXlrL0U5T1FtNlR5Z0hLd0dlTUkvU2xWT2ltbDIxWlVDYUJsdjgyalhSMVd4MzBMZUNtYTJsT3k0QSszcGpVU0Nvbi81K3dhaGVKdEdXaUE3dUlTQm1tZHRpMEZkT0RodCsySndSQ1ZraFlkb1J0TDYxNEkxWkE4SjVJTzFjPQ==/attach/object/JO6NZZZJABQBW?&kso_type=image&kso_extra=eyJ0eXBlIjoiaW1hZ2UiLCJpZCI6IkpPNk5aWlpKQUJRQlciLCJvd25lciI6IjU2MzU3NTA5MzgyMCIsInJvdGF0ZSI6MCwic3RvcmFnZSI6ImJhc2UiLCJ3aWR0aCI6MTYwMiwiaGVpZ2h0Ijo5ODd9)

#### 世界坐标

世界坐标是**物体在游戏世界里的真实位置**。

整个泰拉瑞亚世界是一张巨大的地图，世界坐标就是以这张地图的左上角为原点 (0, 0)，向右为 X 正方向，向下为 Y 正方向。

不管你走到哪里，一棵树的世界坐标是固定的——它就在那个位置，不会因为你移动而改变。

我们平时操作的 `Projectile.position`、`NPC.Center`、`player.Center` 全都是世界坐标。

#### 屏幕坐标

屏幕坐标是物体**相对于玩家屏幕左上角的位置。**

你的屏幕只是一个“窗口”，透过它看到世界的一部分。屏幕坐标描述的是：这个东西，画在屏幕上的哪个位置。

屏幕左上角是` (0, 0)`

向右是 X 正方向，向下是 Y 正方向

屏幕右下角大概是 (屏幕宽度, 屏幕高度)

也就是说，屏幕坐标的范围是很小的，假设你的屏幕只有 `1920×1080` 那么大，所以屏幕坐标的 X 只会在 `0~1920` 之间，Y 只会在 `0~1080` 之间。

#### **注意**

**泰拉里面的绝大部分画面都只在屏幕坐标范围内绘制，**游戏为了性能，不会去画屏幕外的东西，因为画了也看不到，白白浪费计算资源。

所以，到了绘制层面，我们需要把**世界坐标转化为屏幕坐标**，只有这样你的绘制才能在屏幕上生效。

假设你直接把**世界坐标**传给 `Draw()`，游戏会以为“这个东西要画在屏幕上的 `(5000, 1200)` 位置”但你的屏幕最大只有 `1920×1080`，那么这个图片会绘制在屏幕外面，导致你什么都看不到。



那么我们如何把**世界坐标转化为屏幕坐标**呢，其实很简单，**Main**里面提供了一个值：

- Vector2 screenPosition;

  写的时候只要写`Main.screenPosition`就行了，这个值存储着当前**基准屏幕坐标**，

  只需要把**你需要绘制实体的世界坐标**，减去`Main.screenPosition`就能够得出**实体的屏幕坐标**了。

### 绘制流程

知道了屏幕坐标接下来该绘制了，但是有一点要注意，**初学者一定不要在没有SpriteBatch为参数的重写函数里写绘制函数！！！**

比如GlobalNPC类里的PreDraw就是可以绘制的函数：

```csharp
public class DemoGlobalNPC : GlobalNPC
{
    public override bool PreDraw(NPC npc, SpriteBatch spriteBatch, Vector2 screenPos, Color drawColor)
    {
        return base.PreDraw(npc, spriteBatch, screenPos, drawColor);
    }
}
```

注意那个`SpriteBatch`，圈起来考试要考。`SpriteBatch`是一个绘制接口，让你可以在屏幕上绘制一些图案，但是使用要求较为苛刻，所以初学者不要在其他没有SpriteBatch参数的重写函数里面使用。

接下来我们试着写spriteBatch.Draw，

这个函数的重载很多，很难用好：

- public void Draw(Texture2D texture, Vector2 position, Color color)

- public void Draw(Texture2D texture, Vector2 position, Rectangle? sourceRectangle, Color color)

- public void Draw(Texture2D texture, Rectangle destinationRectangle, Color color)

- public void Draw(Texture2D texture, Rectangle destinationRectangle, Rectangle? sourceRectangle, Color color)

- public void Draw(Texture2D texture, Rectangle destinationRectangle, Rectangle? sourceRectangle, Color color, float rotation, Vector2 origin, SpriteEffects effects, float layerDepth)

- public void Draw(Texture2D texture, Vector2 position, Rectangle? sourceRectangle, Color color, float rotation, Vector2 origin, float scale, SpriteEffects effects, float layerDepth)

- public void Draw(Texture2D texture, Vector2 position, Rectangle? sourceRectangle, Color color, float rotation, Vector2 origin, Vector2 scale, SpriteEffects effects, float layerDepth)

  在这里我推荐初学者使用的函数重载是：

  ```csharp
  public void Draw(Texture2D texture, Vector2 position, Rectangle? sourceRectangle, Color color, float rotation, Vector2 origin, float scale, SpriteEffects effects, float layerDepth)
  ```

  在VS中，自动补全提示的应该是第六个重载，**一定要看仔细了，不要按照提示写了其他重载导致划红线。**

  我们一步一步来看这些参数是干什么的：

  

  **Texture2D texuture**，这个参数代表了需要传入的图片，注意这个图片必须是**Texture2D**格式，获取图片的方法有：

  ```csharp
  Texture2D tex = ModContent.Request<Texture2D>("CosmicWeaver/Experiment/Arrow").Value;
  ```

  这样就能读取到`CosmicWeaver/Experiment`目录下的`Arrow.png`图片了。

  

  **Vector2 position**，**注意，这是屏幕坐标**。图像要被绘制位置的屏幕坐标，在我推荐在这里填写类似`XXX.Center-Main.screenPosition`的代码，绘制位置就是那个物体的中心。

  

  **Rectangle? sourceRectangle**，这个参数代表需要绘制被绘制贴图（texuture），的哪一部分，如果全部绘制就是null，一般情况下是null，绘制帧图的时候才需要设置其他值。

  

  **Color color**，要把绘制图片染成什么颜色，一般来说Color.White（不染色）就行了，这个染色系统跟你们认知的染色方式不太一样，不推荐设置为其他值，除非你知道你在做什么。

  

  **float rotation**，图像的旋转弧度，跟其他XXX.rotation一样，自己看着填。

  

  **Vector2 origin**，解释起来比较麻烦，大概就是图像从哪个位置开始扩散（也可以理解为中心点），如果你position填了中心位置，那么这里就填tex.Size()\*0.5f。如果是左上角位置就填Vector2.Zero。

  

  **float scale**，图像缩放倍数。

  

  **SpriteEffects effects**，图像的翻转，可以水平翻转也可以垂直翻转，有需要的时候会有用的，其他时候SpriteEffects.None足矣。

  

  **float** **layerDepth** 是同一批绘制里的前后顺序，`0f` 在底，`1f` 在顶。初学者无脑填0就完事了。

  然后我给你们看看图中的效果的代码：

  ```csharp
  Texture2D tex = ModContent.Request<Texture2D>("CosmicWeaver/Experiment/Arrow").Value;
  
  Vector2 worldPos = new Vector2(npc.Center.X, npc.position.Y - tex.Height);
  
  spriteBatch.Draw(tex, worldPos - Main.screenPosition, null, Color.White, 0f, tex.Size() * 0.5f, 1f, SpriteEffects.None, 0f);
  ```

  这段代码的大体意思为：通过`Texture2D tex`加载图片，通过`Vector2 worldPos`转化坐标，这里坐标定位的地方是npc头顶，然后调用绘制函数`spriteBatch.Draw`进行绘制，我们的图片就绘制好了。

  

  教程的最后我来讲一讲文字绘制，跟上面的要求差不多，但是文字绘制的函数建议使用`Utils.DrawBorderString()`而不是`spriteBatch.DrawString()`。

  这样更符合泰拉瑞亚的文字效果。

  ```csharp
  public static Vector2 DrawBorderString(SpriteBatch sb, string text, Vector2 pos, Color color, float scale = 1f, float anchorx = 0f, float anchory = 0f, int maxCharactersDisplayed = -1)
  ```

  如果你想要使用非默认字体 + 自己控制描边颜色

  或是需要四方向描边（`Utils.DrawBorderString()`是八方向描边，四方向描边比八方向略细）

  可以使用

  ```csharp
  public static void DrawBorderStringFourWay(SpriteBatch sb, DynamicSpriteFont font, string text, float x, float y, Color textColor, Color borderColor, Vector2 origin, float scale = 1f)
  ```

  具体实现大家可以看**TemplateMod**的源码来了解，`DynamicSpriteFont font`这个参数就是文字的字体，一般设置为`Main.fontMouseText`。就是原版鼠标字体。
