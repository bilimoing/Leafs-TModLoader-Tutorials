# 如何制作一个挥舞的剑

1. #### 制作挥舞动作

   想象一下，所谓**挥舞**在泰拉瑞亚里面的表现，其实就是画圆——以玩家的手为圆心，剑体为半径，画一个圆出来。你可能会想："欸？那如何把弹幕固定在手上旋转呢？"

   其实，为了更好的记录挥舞路径，我会更推荐制作出一个**假弹幕**。其实就是把原本的弹幕给取消绘制，让该弹幕的视觉效果以及碰撞全部放在手上。这里 AI 的代码非常简单，只需要用两个 `Vector2` 变量，然后记录一下刀的尾部和首部位置就行：

   ```csharp
   public Vector2 SwordEnd;
   public Vector2 SwordHead;
   ```

   好了，我们现在有了刀的首部和尾部。那我们该如何制作旋转呢？旋转时候又需要什么呢？

   和上面给出的代码一样，我们需要几个旋转值来记录：也就是点击鼠标时的鼠标弧度、起始弧度、当前挥舞弧度，以及总共需要挥舞的弧度与总挥舞时长。

   ```csharp
   public float startRad;//起始弧度
   public float statSwingRad;//当前挥舞弧度
   public float swingRad;//总挥舞所需弧度
   public float swingTimeMax;//总时长
   public float swingTime;//当前时长
   //该方法为弹幕生成时所调用的 也就是在弹幕生成的时候 我们记录一次鼠标位置
   public override void OnSpawn(IEntitySource source)
   {
       Vector2 mousePos = Main.MouseWorld - Main.player[Projectile.owner].Center;
       float mouseRad = MathF.Atan2(mousePos.Y, mousePos.X);
       startRad = mouseRad - swingRad/3f * Main.player[Projectile.owner].direction;
   }
   ```

   好了 准备工作做完 我们开始挥舞吧！ 

   其实也很简单 每一帧把**Time+1** 然后把Time/TimeMax给旋转方法就行。

   我这边给出旋转方法 ：

   ```csharp
   public override void AI()
   {
       //用于保持玩家使用弹幕 开启手持弹幕
       Main.player[Projectile.owner].heldProj = Projectile.whoAmI;
       Main.player[Projectile.owner].itemAnimation = 2;
       Main.player[Projectile.owner].itemTime = 2;
       //固定弹幕位置
       Projectile.Center = Main.player[Projectile.owner].Center;
       //计算旋转进度
       float progress = swingTime/swingTimeMax;
       progress = MathHelper.Clamp(progress, 0f, 1f);
       progress = 1f - MathF.Pow(1f - progress, 3f);
   
       swingTime++;
       //计算当前弧度
       statSwingRad = startRad + swingRad * progress * Main.player[Projectile.owner].direction;
       //传参
       Projectile.rotation = statSwingRad;
       SwordEnd = Projectile.Center;
       SwordHead = Projectile.Center + new Vector2(50f, 0f).RotatedBy(statSwingRad);
       //控制手部旋转
       Main.player[Projectile.owner].SetCompositeArmFront(true,Player.CompositeArmStretchAmount.Full,statSwingRad - MathF.PI/2);
   }
   ```

   是不是很简单？通过当前的挥舞进度来获得当前的挥舞弧度。嗯嗯，很好啊很好啊。欸？这个 `direction` 是干什么用的？？？？？

   其实，这个 `direction` 是通过玩家的方向，来**计算相对应的起点以及旋转增值**。

   **2. 绘制剑体**

   这边使用顶点绘制来制作。什么什么，你说你没学过顶点绘制？？？（我简要概括一下：类似制作一个画布，画布的大小需要你用顶点来选择。也就是说，这个剑体其实是一个正方形的画布，但是画布上面的内容只有一个剑本身而已。简要概括完毕。如果想学清楚一点的话，这边推荐去问问 AI，或者看看「[裙裙的模组制作高级教程1\_哔哩哔哩\_bilibili](https://www.bilibili.com/video/BV1Hy4y1n7RG/?spm_id_from=333.1387.homepage.video_card.click&vd_source=bf9a6a950271e4958dc5fbaffb750260)」这个。）

   好，那我们继续讲：通过用顶点做画布，来把剑固定在手上。我附上需要的顶点结构以及绘制代码。

   ```csharp
   public struct Vertex : IVertexType
   {
       private static VertexDeclaration _vertexDeclaration = new VertexDeclaration(new VertexElement[3]
       {
           new VertexElement(0, VertexElementFormat.Vector2, VertexElementUsage.Position, 0),
           new VertexElement(8, VertexElementFormat.Color, VertexElementUsage.Color, 0),
           new VertexElement(12, VertexElementFormat.Vector3, VertexElementUsage.TextureCoordinate, 0)
       });
   
       public Vector2 Position;
       public Color Color;
       public Vector3 TexCoord;
   
       public Vertex(Vector2 position, Vector3 texCoord, Color color)
       {
           Position = position;
           TexCoord = texCoord;
           Color = color;
       }
   
       public VertexDeclaration VertexDeclaration
       {
           get => _vertexDeclaration;
       }
   }
   ```

   以上为一个顶点结构体 这个我就不讲了 想了解的话 也可以去问问AI或者网上搜索相关内容。

   我们的重点放在这里 ↓↓↓↓↓↓↓↓

   ```csharp
   public override bool PreDraw(ref Color lightColor)
   {
       SpriteBatch sb =  Main.spriteBatch;
       Vector2 handle = SwordEnd - Main.screenPosition;
       // 两个世界坐标相减才是剑身向量 不能再减屏幕位置。
       Vector2 blade = SwordHead - SwordEnd;
       Vector2 half = blade * 0.5f;
       //你要是不知道(-y,x)这个东西的意思 我推荐你回顾一下初中数学！
       Vector2 side = new Vector2(-half.Y, half.X);
       
       Vector2[] swordPos_Draw =
       [
           handle + half - side, // 左上
           handle + blade,       // 右上：剑尖
           handle,               // 左下：剑柄
           handle + half + side  // 右下
       ];
       // 三角形带只需四个顶点 顺序是左上 左下 右上 右下
       Vertex[] sword =
       [
           new Vertex(swordPos_Draw[0], new Vector3(0, 0, 0), Color.White),
           new Vertex(swordPos_Draw[2], new Vector3(0, 1, 0), Color.White),
           new Vertex(swordPos_Draw[1], new Vector3(1, 0, 0), Color.White),
           new Vertex(swordPos_Draw[3], new Vector3(1, 1, 0), Color.White)
       ];
       sb.End();
       sb.Begin(
           SpriteSortMode.Immediate,
           BlendState.AlphaBlend,
           SamplerState.AnisotropicClamp,
           DepthStencilState.None,
           RasterizerState.CullNone,
           null,
           Main.GameViewMatrix.TransformationMatrix
       );
       Main.graphics.GraphicsDevice.RasterizerState = RasterizerState.CullNone;
       Main.graphics.GraphicsDevice.Textures[0] = TextureAssets.Projectile[ModContent.ProjectileType<TestSword>()].Value;
       Main.graphics.GraphicsDevice.DrawUserPrimitives(PrimitiveType.TriangleStrip, sword, 0, 2);
       sb.End();
       sb.Begin(SpriteSortMode.Deferred, BlendState.AlphaBlend,
           Main.DefaultSamplerState, DepthStencilState.None, RasterizerState.CullNone,
           null, Main.GameViewMatrix.TransformationMatrix);
       return false;
   }
   ```

   这里是用`SwordHead` 和`SwordEnd`取得剑的起点终点 然后减去世界坐标变成屏幕坐标(注: 这里减去世界坐标的原因是因为渲染管线里面的矩阵没有转换世界坐标) 然后取这条线的中点 再从终点获取(-y,x)的垂直线 一个+垂直线 一个 -垂直线  就可以拼出一个用于绘制剑身的长方形

   `Main.graphics.GraphicsDevice.Textures[0]` 代码是给渲染管线上贴图。在后面的课里面，会使用到着色器对刀光进行操作。这里只需要知道，这个代码需要传入的贴图就是你想绘制的那个贴图。

# 开始制作刀光

1. #### 记录位置

   我们要把剑体挥过去的位置找到 这个时候 咱们的SwordHead就能发挥作用了

   首先 我们先制作一下记录位置所需要的方法 我也是直接给出我自己的代码(**注意这里新创建了两个数组**)

   ```csharp
   public void SavePos(Vector2 headpos,float rot,Vector2 endpos)
   {
       //这里的30意为去30个路径上的点 实例数组时同步
       for (int i = 30 -1; i > 0; i--)
       {
           oldHeadPos[i] = oldHeadPos[i - 1];
           oldRot[i] = oldRot[i - 1];
           oldEndPos[i] =  oldEndPos[i - 1];
       }
       oldHeadPos[0] = headpos;
       oldRot[0] = rot;
       oldEndPos[0] = endpos;
   }
   ```

   非常清爽的写法 每一帧都把上一帧的数值给拿走 然后再记录当前帧的数值。

    (~~如果看不懂你就要去补习补习了~~)  

   然后在AI()里面  在控制手部旋转的语句上一行 加上这个

   ```csharp
   SavePos(SwordHead - SwordEnd,statSwingRad,SwordEnd);
   ```

   用来调用方法以及记录数据 自此 位置记录就结束了 接下来绘制刀光

   然后给出代码

   ```csharp
   private void DrawTrail(SpriteBatch sb, Color color)
   {
       if (savedPosCount < 2)
           return;
   
       // 所有记录共用当前剑柄位置 只保留过去的挥舞方向和剑长。
       Vector2 handle = SwordEnd - Main.screenPosition;
       for (int i = 0; i < savedPosCount; i++)
       {
           float progress = i / (float)(savedPosCount - 1);
           Vector2 tip = handle + oldHeadPos[i];
           Color trailColor = color * (1f - progress);
   
           // U 从最新记录的 0 走向尾部的 1；V 从剑柄的 0 走向剑尖的 1。
           trailVertices[i * 2] = new Vertex(handle, new Vector3(progress, 0f, 0f), trailColor);
           trailVertices[i * 2 + 1] = new Vertex(tip, new Vector3(progress, 1f, 0f), trailColor);
       }
   
       Texture2D texture = ModContent.Request<Texture2D>(
           "自己的刀光图路径",
           ReLogic.Content.AssetRequestMode.ImmediateLoad).Value;
       sb.Begin(SpriteSortMode.Immediate, BlendState.Additive,
           SamplerState.LinearClamp, DepthStencilState.None, RasterizerState.CullNone,
           null, Main.GameViewMatrix.TransformationMatrix);
       Main.graphics.GraphicsDevice.Textures[0] = texture;
       Main.graphics.GraphicsDevice.DrawUserPrimitives(
           PrimitiveType.TriangleStrip, trailVertices, 0, savedPosCount * 2 - 2);
       sb.End();
   }
   ```

   以上即为绘制刀光的方法 原理就是通过顶点造画布 然后UV对齐后直接绘制 贴图背景的黑色 可以通过Add的色彩模式 让其消失 然后就是同样的**渲染管线**的东西了 

   接下来我们只需要在`PreDraw`的第一个`sb.End();` 后面调用

   ```csharp
   DrawTrail(sb, Color.White);
   ```
