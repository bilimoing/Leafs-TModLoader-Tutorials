### 平面向量概念

先上定义：

***平面向量**是在二维平面内既有**方向**(direction)又有**大小**(magnitude)的量。与之相对的是只有大小、没有方向的量（标量）。*

我们知道，TR是一个二维游戏，所有的物体的运动情况都是需要在一个**二维平面**内表示的，或者说，一个平面直角坐标系来表示。

![图片](images/tutorials/e84f8c5592f6ff062092d96d.png)

如图所示，**OA**就是一个二维向量，因为它有大小（**OA**这条线段的长度），和方向（从点O到A）。这个箭头所指示的就是向量的方向，如果箭头是反着的，那么向量的方向也是反的。

我们把向量**OA**这条线段的长度叫做**向量的大小**，现在我们要确认的就是**OA**方向，一般来说，我们描述这个方向就是用**OA与X轴的夹角**来描述。

![图片](images/tutorials/05feac06396e821bed00b39e.png)

向量的表示

还有一种描述向量的方式就是用**数对**，比如图中的**OA**向量就可以用(2,1)来表示。如果向量方向相反（**AO**），那么就需要用(-2,-1)表示了，因为这时候该以A作为原点了。

#### 向量的加减乘除与标量不同，假设有两个向量OA，OB，

![图片](images/tutorials/c296d59125284576b260b2a3.png)

那么**OA+OB**就应该是这样的：

![图片](images/tutorials/a5af2529f3482bcd01af7c21.png)

如图所示，OB∥AB’，**OA+OB**的结果就是**OB’**，向量的加法其实就是他们大小和方向的结合，可以看做先以O为原点从点O到点A，然后以A为原点，加上一个点O到点B的路径。另一种解释方式就是两个向量的**数对的和**，比如**OA**是(2,1)，**OB**是(1,-1)，那么**OA+OB**就是(2,1) + (1,-1) = (3, 0)，也就是**OB’**向量的值。

那么我们怎么理解向量的减法，**OA-OB**呢？其实我们可以把**OA-OB**看做**OA+BO**，也就是**OA**向量加上**OB向量的反方向**，也就是如下图的样子：

![图片](images/tutorials/a1f4c8b3d8b4170ed8f34935.png)

**BA**也就是我们要的结果。其中**AB’**就是**OB**的反向向量，并且平移到了点A的位置，所以**OA+AB’**就是**OA-OB**了。同样，我们也可以用数对的方式来验证这个答案，**OA-OB**就是(2,1) - (1,-1) = (1,2)，而OB’向量的值正是(1,2)，所以答案正确！

**TR中影响弹幕飞行速度，玩家移动速度的值就是向量的长度。**

**向量的乘法**，因为向量乘以向量在TR里面用的少，所以先不考虑向量乘以向量的情况，而是考虑向量乘以标量的情况。所谓向量乘以标量，就是类似**OA×5**这样的表达式，把一个向量乘以一个数值，其实就是把向量的长度延伸或者缩减一定倍数。比如OA×2其实就是把**OA**这个向量延长一倍：

![图片](images/tutorials/8224179d122c2b30e1ea5c66.png)

如图所示，**OA’**就是向量乘以2的结果。**同理，如果除以2那么向量的长度就会缩减到原来的一半，如果乘以一个负数就会把向量的方向反过来。**

那么你们要问了，学这些向量的公式和写弹幕有什么关系？事实上弹幕的运动轨迹，NPC的运动轨迹，AI什么的都离不开这些知识，尽管现在看起来这些知识很枯燥，但是以后会有大用处的。

最后再介绍一个操作，**标准化**（Normalize），这是一个非常重要的操作，在介绍他之前，我们先要定义一下什么叫**单位向量**。我们知道标量中有单位长度的概念，代表着最基本的长度。向量也是一样，**我们把长度为1的向量称为单位向量**，也就是说，单位向量有固定的大小1，但是方向却不固定。而**标准化**操作就是把一个**任意向量变成单位向量。**

为了把向量**OA**变成单位向量，我们要做的很简单，就是保持方向不变的情况下，把**OA**长度缩减到1。当然把长度缩减为1其实就是把OA向量除以它的长度就行了。所以说，一个向量的单位向量的公式为：

### TR坐标系

---

TR中的坐标系与平面直角坐标系（也称Cartesian coordinates）不同，对于平面直角坐标系来说，以X轴正方向为右边，以Y轴正方向为上

![图片](images/tutorials/6e6a129a85a6ea59c254b907.png)

平面直角坐标系

而TR的坐标系是X轴正方向是右边没错，但是Y轴正方向却是下

![图片](images/tutorials/c900f455e7655c65a2ed6116.png)

TR坐标系

这点令人有点讨厌，不过问题不大，只要记住往下是正，往上是负的就好了。所以我们在做自由落体弹幕的时候，用的是projectile.velocity += 0.5f;

### Vector2类型

---

TR中为了表示这些二维向量，给我们提供了一个超级好用的类型，那就是Vector2，这个数据类型有两个属性，X和Y，并且这两个属性都是float类型。Vector2的构造函数中可以为这两个属性赋值，方法为：

```csharp
// 声明一个Vector2变量，X轴大小为5.0f，Y轴大小为3.0f
Vector2 vector = new Vector2(5.0f, 3.0f);
```

同时，Vector2也重载的操作符，所以我们可以直接对Vector2进行加减乘除操作：

```csharp
// 声明一个Vector2变量，X轴大小为5.0f，Y轴大小为3.0f
Vector2 vector = new Vector2(5.0f, 3.0f);
// 声明一个Vector2变量，X轴大小为5.0f，Y轴大小为3.0f
Vector2 vector1 = new Vector2(-5.0f, -3.0f);
// 打印出这些二维向量操作的结果
Main.NewText(vector + vector1);
Main.NewText(vector - vector1);
Main.NewText(vector * 5.0f);
```

这些代码写在哪你们自己决定，能看到结果就好了，不知道写在哪的我推荐你重新看教程。

![图片](images/tutorials/48ca173280f89518d556c653.png)

Vector2这个类型的函数可真不少，其中就有我们的标准化函数，这个函数输入一个二维向量，输出这个二维向量的单位向量，很棒呢，这样就不用手动计算单位向量了。

此外，Length也是一个很常用的属性，它的作用就是得到这个向量的长度，用法：vector.Length()，返回一个float类型的数据。
