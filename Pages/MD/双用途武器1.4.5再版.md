**双用途武器制作**

双用途武器的一个核心函数是：

![图片](images/tutorials/effe8c6b1a262471ea5f4b00.png)

```csharp
public override bool AltFunctionUse(Player player)
{
    return true;//返回true 会让武器右键时也被使用
}
```

**AltFunctionUse**函数，它在返回true时会让武器右键时也被使用。



而核心字段为P**layer**的**altFunctionUse，**

当你按下右键的时候泰拉瑞亚会把**player.altFunctionUse**的属性设置为2

我们只需要判断这个属性的值，就能够知道玩家是否通过右键使用武器。



这里改把手枪实验一下：

![图片](images/tutorials/b5a8480d6b04682bcc318f00.png)

![图片](images/tutorials/c22e41a0893a207e09234ac6.gif)

~~非常好用~~



**Item**物品的右键默认**无法连续使用**，想要让武器右键也能连续使用，需要将**ItemID.Sets.ItemsThatAllowRepeatedRightClick[Type]** 设置为 **true**

![图片](images/tutorials/d1be53da69141509e9bc6522.png)

在**SetStaticDefaults**函数里给整个物品全局设置

![图片](images/tutorials/22b8238f022af7d6dd0a2a7f.gif)

```csharp
public override void SetStaticDefaults()
{
    // 关键：允许右键连续使用
    ItemID.Sets.ItemsThatAllowRepeatedRightClick[Type] = true;
}
```

为了做到更多不同的效果（调整物品大小，修改消耗魔力值，使用不同类型的子弹等），我们可能会对Item物品本身进行修改。这里我推荐在**CanUseItem**重写函数里面修改物品数值。

![图片](images/tutorials/45c5a53cb1311142255bbcd5.png)

**CanUseItem**重写函数会在玩家物品被尝试使用之前执行一次，用于判断这个物品**能不能被使用？**返回**true**就允许物品被使用，返回**false**就禁止。

我们在**CanUseItem**函数修改数值，以保证在物品被使用之前将其数值修改；

```csharp
public override bool CanUseItem(Player player)
{
    // 判断玩家是否是右键使用
    if (player.altFunctionUse == 2)
    {
        // ===== 右键逻辑 =====
        // 设置右键发射的弹幕类型（追踪弹）
        Item.shoot = ModContent.ProjectileType<ChasePro>();
        // 设置弹幕飞行速度
        Item.shootSpeed = 5f;
        // 右键不消耗任何弹药
        Item.useAmmo = AmmoID.None;
        // 右键使用时间（数值越大越慢，40 表示约 0.67 秒一次）
        Item.useTime = 40;
        Item.useAnimation = 40;
    }
    else
    {
        // ===== 左键逻辑 =====
        // 设置左键发射的弹幕类型（爆炸子弹）
        Item.shoot = ModContent.ProjectileType<ExplodingBullet>();
        // 设置弹幕飞行速度
        Item.shootSpeed = 5f;
        // 左键消耗子弹类弹药
        Item.useAmmo = AmmoID.Bullet;
        // 左键使用时间（数值越小越快，4 表示非常快）
        Item.useTime = 4;
        Item.useAnimation = 4;
    }

    // 允许使用该物品
    return true;
}
```

这里有一些细节需要注意。我们在**左键修改完字段数值**以后，在右键要把**左键修改过的所有字段**修改回去，否则会出现，武器使用右键攻击以后，左键攻击无法还原的情况（还是右键的攻击方式）。

所以物品的**状态还原**十分重要。
