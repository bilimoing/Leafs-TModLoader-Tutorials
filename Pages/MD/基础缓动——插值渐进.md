# 引例：仅一行代码实现平滑的追击运动

![图片](images/tutorials/f0ea1d432b3a3e1fab665a91.gif)

```csharp
Projectile.velocity = Vector2.Lerp(Projectile.velocity, Projectile.DirectionTo(Main.MouseWorld) * 20f, 0.05f);
```

## 简介

**插值渐进**，指每帧让某个变量向着目标变化一固定比例，以实现平滑运动的方法。在tmod中非常好用，可以简单地让运动、旋转不再僵硬，广泛运用于BossAI，弹幕AI，手持武器等方面。

![图片](images/tutorials/73d589cc3553358e76de5be8.png)



## 解析

上面那一行的解析：

```csharp
Vector2 targetPos = Main.MouseWorld; //目标位置
Vector2 targetVel = Projectile.DirectionTo(targetPos) * 20f; //目标速度：指向目标位置的20大小向量
float t = 0.05f; //插值量（0到1之间），决定速度变化快慢，越小则变化越缓
Projectile.velocity = Vector2.Lerp(projectile.velocity, targetVel, t); //执行插值
```

其中，Entity.DirectionTo(Vector2 pos)是常用的扩展方法，能求实体指向pos位置的单位向量。但原版这个单位化过程没有考虑0向量，可能会有错误，所以实际情况建议自制如下扩展方法：

```csharp
public static Vector2 DirectionTo2(this Entity entity, Vector2 target)
{
    return target - entity.Center != Vector2.Zero ? Vector2.Normalize(target - entity.Center) : Vector2.Zero;
}
```



# 基础运动方法组

## 速度插值

对于例子中的移动方法，可封装为基础移动函数，写进模组的辅助函数库中：

```csharp
public static void MoveTo(this Entity entity,Vector2 targetPos,float targetSpeed,float t)
{
    entity.velocity = Vector2.Lerp(entity.velocity, entity.DirectionTo2(targetPos) * targetSpeed, t);
}
```

这样例如在npc中，只需要调用：

```csharp
npc.MoveTo(player.Center,10,0.05f); //朝玩家，目标速度10，插值量0.05
```

就能实现对目标位置的移动。

## 位置插值

另外，插值渐进不仅可以对速度，还可以直接对位置：

```csharp
public static void StraightMoveTo(this Entity entity, Vector2 targetPos, float t)
{
    entity.Center = Vector2.Lerp(entity.Center, targetPos, t);
}
```

这样的运动相当直接，适合快速运动到某个位置，或者锁定维持一个位置。

例如光之女皇在很多攻击结束时都快速回到玩家附近的移动方式。

使用时最好将velocity归0，避免干扰。

## 其它插值

插值不仅可以作用于向量。

对于float类型，有MathHelper.Lerp,

对于Color类型,有Color.Lerp,

其中角度推荐使用Terraria.Utils.AngleLerp，避免超出范围的角度出现问题，但如果刻意要用插值旋转好几圈，还是得用MathHelper.Lerp。

渐进旋转：

```csharp
public static void RotateTo(this NPC npc, float targetRot, float t)
{
    npc.rotation = Utils.AngleLerp(npc.rotation, targetRot, t);
}
```

# 背后的原理与优缺点分析

Lerp = linear interpolation，线性插值

$lerp(a,b,t)=a+(b-a)*t$

例如：当一个变量x初值为x0时，每帧执行x=lerp(x,target,0.5)时

![图片](images/tutorials/9d461712128118f345bcccd6.png)

x每帧会变为x与目标target的中点位置，从而实现渐进。

运动的曲线为：（这里的t是时间，以帧为单位）

$x(t)=lerp(target,{{x}_{0}},{{(1-0.5)}^{t}})$

显然是个指数曲线。

## 优点

非常方便，不受初始值影响，给定目标值即可缓动。

## 缺点

理论上永远无法抵达目标，只能无限接近，因此仅适用于无需必定抵达目标的变化。

对于非固定帧数的情况，变化速度受帧数影响，需要如下改进：

# 推广到非固定帧率

泰拉瑞亚固定每秒60帧的情况下，上述方法可以直接用。

但如果一个游戏每秒120帧，插值的执行速度也翻了一倍，就会导致效果执行过快。

这时候需要调整插值量t的值来维持效果不变。

以Unity为例：

```csharp
t = 1 - Mathf.Pow(1 - t, Time.deltaTime / 0.01667f);
```

其中，Time.deltaTime为当前游戏帧数下两帧的间隔时间，

0.0166...则是60帧下两帧的间隔时间（1/60）作为基准（也可以换其它数）,

这样就能把各种帧数下的效果统一了。
