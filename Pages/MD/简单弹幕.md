# **简单弹幕**

说了这么多，那么在游戏里，到底什么是弹幕呢？

**弹幕**，英文名 **Projectile**，简称 **proj**，是由**物品、NPC、陷阱** 等来源生成的实体。它不一定只是“飞出去造成伤害的东西”，游戏里的弹幕的种类非常繁多，大致可以分为几类：



**攻击型：**负责造成伤害，比如子弹、箭、火球

**演出型：**负责视觉效果，比如光之女皇的生成动画、Boss出场特效

**手持型：**贴合玩家手部，作为物品的视觉延伸，比如电钻、长矛



所以简单来说，弹幕就是游戏里“被发射出来、独立存在、有自己行为逻辑的实体”。

![图片](images/tutorials/05084687a901d2ad6e41b225.png)

不过在创建弹幕之前，我们需要在我们的**Content**文件夹下新建一个文件夹，并且起名为**Projectiles**，然后在这个文件夹内新建一个**cs文件**，随便起一个名字（我这里使用**DemoProj**你们随意）作为文件名。

![图片](images/tutorials/25c8a032f854a65e131ba9f8.png)

然后将教程提供的贴图放入其中，并保证**图片名，类名，文件名**一致。

![图片](images/tutorials/c14833c26de093a6681f019a.png)

之后的步骤和创建Item类似，我们需要一个名为 **DemoProj**的公开类（**public**），并且继承自 **ModProjectile**（表示这是一个**模组弹幕**）这些基本的创建流程以后就不会讲了。

代码如下：

```csharp
using Microsoft.CodeAnalysis;
using Microsoft.Xna.Framework;
using System;
using System.Collections.Generic;
using Terraria;
using Terraria.Audio;
using Terraria.ID;
using Terraria.ModLoader;

namespace DemoMod.Content.Projectiles
{
    public class DemoProj : ModProjectile
    {

    }
}
```

之后我们要设置**弹幕的基础属性。**

```csharp
public override void SetDefaults()
{
    Projectile.width = 16;           // 弹幕碰撞箱宽度
    Projectile.height = 16;          // 弹幕碰撞箱高度
    Projectile.friendly = true;      // 对敌人造成伤害
    Projectile.hostile = false;      // 对玩家造成伤害
    Projectile.DamageType = DamageClass.Magic;  // 伤害类型：魔法
    Projectile.penetrate = 3;        // 穿透次数（-1表示无限穿透）
    Projectile.timeLeft = 300;       // 存活时间（60帧=1秒，300=5秒）
    Projectile.light = 0.5f;         // 发光强度
    Projectile.ignoreWater = true;   // 不受水影响
    Projectile.tileCollide = true;   // 撞墙消失
    Projectile.extraUpdates = 1;     // 额外更新次数，让弹幕更流畅
}
```

弹幕的基本属性和物品的属性有很大的不同，但和物品一样，它们都是在**SetDefaults()**方法里设置的。 将这段代码粘贴进我们的文件。

![图片](images/tutorials/a884d4cee8b5213048c307ac.png)

我们先来看这两个基本属性：

![图片](images/tutorials/e4bbe36be4ef5ea254326d05.png)

**width（碰撞箱宽度）** 和 **height（碰撞箱高度）**

这里的宽度和高度，指的是弹幕的**碰撞体积（Hitbox）**的宽度和高度，不是视觉上看起来的大小。



如果你了解过泰拉的弹幕贴图，你会注意到很多图都是以头朝上的格式绘制的，这是为什么呢？

因为泰拉瑞亚的弹幕是按照**碰撞体积（Hitbox）**来判定伤害碰撞的。一般来说，我们都会把碰撞体积设置得比贴图本身小一些，这样弹幕能在视觉上“看起来合理”，而不是图片没有碰到敌人就判定命中。



在泰拉瑞亚中，弹幕的碰撞体积**坐标原点**是在**图片的左上角**，从左上角开始向右下延伸，如图所示。

|![图片](images/tutorials/602621da780870610b5bc5ef.png)|![图片](images/tutorials/614e929c46f4ba08039dcbc3.png)|
|---|---|



这样设置之后，碰撞体积就**比较接近真实的伤害位置**。

但如果你把弹幕**横着画**：

![图片](images/tutorials/bd5d1e162d66fe4c1d2b73c2.png)



那么伤害位置就对不上了，因为游戏仍然按照左上角为原点来判定碰撞，而你的图片视觉重心可能在别的地方。所以一般来说，弹幕最好头**朝上画**，除非你使用 **Draw**方法自己绘制弹幕（完全自定义碰撞和视觉的关系，在后面的绘制教程中会详细说明）。



当然，你也可以把碰撞体积设成和图片一样大，但那样很容易出问题。大部分武器的发射位置都在人物中心，如果你站在地上并且弹幕的碰撞体积比人物还大，那么弹幕刚发射出来就会判定碰到物块，直接消失。



过大的弹幕也会在一些很奇怪的位置造成伤害，和视觉上看到的完全不符，作为初学者我们应尽力避免这种情况。



![图片](images/tutorials/4c69a95cf2d509a0ed981b06.png)

然后我们介绍

**friendly（对敌人造成伤害）**字段和**hostile（对玩家造成伤害）**字段

如果你想让这个弹幕能对敌方造成伤害，需要把**friendly**设为**true。**

如果你想让这个弹幕能对友善NPC以及玩家造成伤害，需要把**hostile**设为**true**



两个属性可以共存，对双方都造成伤害！**（巨石，毒箭等）**

![图片](images/tutorials/5615e16262c90bcd1ea64dac.png)

**DamageType** 伤害类型，弹幕的伤害类型决定了弹幕能够享受到哪些加成，比如**近战（熔岩石）、远程（毒刺箭头）、魔法（魔法吸血）、召唤（鞭子标记）**等，还可以享受到这种伤害的特殊效果以及伤害、暴击率增幅（无类型伤害无法暴击）



原版在这个字段的处理上不够细心，导致遗留问题一陀。



比如战士的屠夫链锯出来的火花其实和法师武器火花魔杖的火花是同一个弹幕。属于法师伤害，在1.4.4bug修复之前，因为缺了弹幕伤害与暴击率加成。屠夫链锯一直无法达到理论总伤。



大部分怪物的弹幕都会造成无类型伤害，不会随着弹幕暴击率改变。但少部分弹幕（机械boss与血肉墙使用的激光）会造成魔法伤害，能够对友方npc造成暴击。

![图片](images/tutorials/9cbe3b0ddb6037cf40ee87e9.png)

**penetrate（穿透次数）**决定了弹幕打中几个怪物之后才会消失，穿透数量为1的弹幕不受其他弹幕的无敌帧影响，可以立即结算

![图片](images/tutorials/255255856b8d00c6272ec046.png)

**timeLeft（弹幕的存活时间）**如非必要不要将其动态修改，不然弹幕会一直存在，消耗很多内存和CPU资源，造成游戏卡顿

![图片](images/tutorials/679e6292559c05b0215109ef.png)

**light（发光强度）**弹幕光照的强度，不过在这里设置只能让弹幕发白光

![图片](images/tutorials/45332c7b43cc17002bc121dd.png)

**ignoreWater（不受水影响）**这个属性可以决定弹幕在水里的时候会不会减速，注意true是不受影响

![图片](images/tutorials/7be974a486b491cc24265236.png)

**tileCollide（撞墙消失）**弹幕会不会和**物块碰撞**由这个属性控制，为true则弹幕撞到物块后会消失，否则就会穿墙。

![图片](images/tutorials/f532b4a2be72c9f2b8d723a7.png)

**extraUpdates（额外更新次数）**注意这个额外更新相当于加速键，默认为0



如果把弹幕比做视频，填1的话就相当于播放速度加1倍变成2倍速，填2的话就3倍速。我们在教程末尾会修改它，以直观的查看他对弹幕的影响。



以上就是自制弹幕的一些基本属性了。还有一些更高级的属性我暂时不打算在这里展开讲，它们大多比较复杂，而且往往要结合具体场景才能说清楚。这些内容后面会有单独的篇幅来专门讲解。

现在我们有了自己的弹幕了，但是怎么发射呢？**ItemID**里面肯定是找不到我们自己制作的弹幕的，因为那里面的内容是固定的。我们需要使用**ModContent**提供的**ProjectileType**方法来获取自制弹幕的ID。



在模板剑的**SetDefaults**方法里写上

**Item.shoot = ModContent.ProjectileType&lt;DemoProj&gt;();**

别急（）如果你的弹幕发射出来的是这个样子的，那么恰恰说明我们写成功了。

我们先介绍一个**超级重要的重写函数**：

```csharp
public override void AI()
```

看到名字应该就能猜到了吧？**AI()** 就是决定弹幕行为的地方，也就是弹幕的**行为逻辑。**



这个函数没有参数，也没有返回值。它每秒执行 60 次，也就是说，游戏每运行一帧，它就会被调用一次。在这里你可以修改弹幕的位置、速度、加速度、视觉特效……几乎弹幕的一切行为，都写在这个方法里。 可以说，**AI()** 是弹幕的核心函数，用处非常大。



但这和我们的弹幕的问题有什么关联呢？其实导致弹幕变成这样的原凶是我们忘记了一个需要动态设置的字段：



**rotation，**这个字段被用于弹幕的旋转角度，单位是**弧度（Radians）**所以我们在文件里加上：

```csharp
public override void AI()
{  
    // 让弹幕的贴图方向，始终跟着飞行方向走，我们的贴图是朝上的，所以补偿 +90°
    Projectile.rotation = Projectile.velocity.ToRotation() + MathHelper.PiOver2;
}
```

然后我们进入游戏：

![图片](images/tutorials/4685ba87a69d236f0793964b.gif)

这才对嘛。

教程里提供的

```csharp
Projectile.rotation = Projectile.velocity.ToRotation() + MathHelper.PiOver2;
```

是弹幕朝向的万金油写法，能够适配弹幕运动中的各种动作，我们在弹幕的**Ai()**方法里加入重力影响：

```csharp
public override void AI()
{
    Projectile.velocity.Y += .1f;// 水平下落

    Projectile.velocity.X *= 0.995f; // 水平减速

    // 限制最大下落速度，避免砸得太快
    if (Projectile.velocity.Y > 16f)
    {
        Projectile.velocity.Y = 16f;
    }

    // 让弹幕的贴图方向，始终跟着飞行方向走，我们的贴图是朝上的，所以补偿 +90°
    Projectile.rotation = Projectile.velocity.ToRotation() + MathHelper.PiOver2;
}
```

然后我们进入游戏：

![图片](images/tutorials/d34a8b3d14603f7e7dee1406.gif)

可以看到不管弹幕怎么移动，弹幕方向始终是正确的，非常好用！



弹幕的粒子效果也是在**AI()** 方法这里加的。比如，我想让弹幕带火焰粒子，可以在 **AI()** 里面这么写：

```csharp
Dust dust = Dust.NewDustDirect(
Projectile.position,              // 1. 生成位置
Projectile.width,                 // 2. 生成区域宽度
Projectile.height,                // 3. 生成区域高度
DustID.Torch,                     // 4. 粒子类型 (火焰)
0f,                               // 5. 水平初速度
0f,                               // 6. 垂直初速度
100,                              // 7. 透明度 (Alpha)
default(Color),                   // 8. 颜色 (Color)
3f                                // 9. 大小缩放 (Scale)
);
```

**NewDustDirect**是**Dust**提供的静态工具方法，用于生成粒子。我们会在后面的**自制粒子教程**中详细介绍，现在先按我给出的模板填写。

然后我们进入查看：

![图片](images/tutorials/6e66809b7ae0c83d2b5cc405.gif)

不赖，但是有点过于像个火球了。我们可以让粒子效果分布的不那么散，在粒子代码下面加入：

```csharp
// 粒子特效不受重力
dust.noGravity = true;
// 让粒子默认的运动速度归零
dust.velocity *= 0;
// 让粒子始终处于弹幕的中心位置
dust.position = Projectile.Center;
```
