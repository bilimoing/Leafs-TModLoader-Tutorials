### 三角函数初步

上一讲中，我们提到，向量是具有大小和方向的量，并且学会了向量之间的运算。但是这些运算都是基于向量X，Y分量的，如果我们**只知道向量的长度和与X轴正方向的夹角**，那我们怎么求出向量的两个分量(X,Y)呢？

![图片](images/tutorials/2e215e53a1907d07323ed4da.png)

如果你没有学过三角函数，要求出这个向量的X，Y是很困难的。但是你也不能逃避，因为在TR里面，很多情况下你只知道向量的角度和长度，有时候甚至连长度都不知道，你要是不会计算那可就惨了QAQ。



但是其实你也能隐约感觉到，知道角度和边长以后，X，Y分量的值应该是确定的并且可求的，只是你不知道怎么求。好的，那我就来介绍一下三角函数吧。



**三角函数**其实就是一类函数，这个函数接受一个角度作为参数，输出的是另外两边的比值。不过这个角度在TR里可不是我们常用的度数，而是弧度，所以我还要说一下什么是弧度。



假设一个圆它的半径是1，那么它的周长应该是多少？答案是：2π，（这别告诉我不会）。那如果是个半圆呢？答案：π。如果这个圆是一个90度角的扇形呢？

答案：

![图片](images/tutorials/0be60d6f61d343534ec87472.png)

那么我们说，360度（整圆）的弧度为2π，180度（半圆）的弧度为π，90度角（四分之一扇形）的弧度为

![图片](images/tutorials/0be60d6f61d343534ec87472.png)

所以什么是弧度呢？其实就是在圆的半径为1的时候，在这个角度的情况下，所构成的圆弧的长度。可能不太好理解，那就用动画来解释：

![图片](images/tutorials/26f1a49df222473cee8b5f57.gif)

所以说，弧度其实就是CA的长度是π的多少倍，我们一般用弧度来表示角度，因为这样更精准。

接下来我们先看一下三角函数中最先学的sin函数，假设我们有一个直角三角形OAD：

![图片](images/tutorials/15ad00c0041612276389514c.png)

那么我们把∠AOD叫做θ，把θ所对应的边AD叫做**对边**，把AO这条与直角∠ADO相对的边叫做**斜边**，然后把OD这条第三边叫做**邻边**。那么**sin**这个函数的作用就是根据输入进来的弧度θ，我返回以这个角为直角三角形的对边长度除以斜边长度的值。可以写为：

![图片](images/tutorials/95d8fa563c3b23083045b985.png)

也就是AD除以AO的值。

同理，**cos**这个三角函数也可以表示为：

![图片](images/tutorials/9e06c82efed88000da6d168f.png)

也就是OD的长度除以OA的长度的值。

最后一个基本三角函数是**tan**，它的表示是：

![图片](images/tutorials/a290c1d9e90670c8f3dbb46d.png)

也就是AD的长度除以OD的长度的值。

下面是一张常用的三角函数表：

|**角度**|**0°**|**15°**|**30°**|**45°**|**60°**|**90°**|
|---|---|---|---|---|---|---|
|弧度|0|π/12|π/6|π/4|π/3|π/2|
|sin值|0|[(√6)-(√2)]/4|1/2|(√2)/2|(√3)/2|1|
|cos值|1|[(√6)+(√2)]/4|(√3)/2|(√2)/2|1/2|0|
|tan值|0|2-√3|(√3)/3|1|√3|棍木|


|**角度**|**120°**|**135°**|**150°**|**180°**|**270°**|
|---|---|---|---|---|---|
|弧度|2π/3|3π/4|5π/6|π|3π/2|
|sin值|(√3)/2|(√2)/2|1/2|0|-1|
|cos值|-1/2|-(√2)/2|-(√3)/2|-1|0|
|tan值|-√3|-1|-(√3)/3|0|-棍木|


从上表可以看出，一些常用的角度比如30度所组成的直角三角形的对边比上斜边的值为1/2，也就是说，30度角直角三角形对边的长度是斜边的一半。



那么如果我们知道对边的长度或者斜边的长度，就可以知道另一条边的长度，进而也就能知道所有三条边的长度了。**但是这个方法只适用于直角三角形**。



比如说30度角的斜边长度是100，那么对边的长度就是：

![图片](images/tutorials/d82e10885c37b4bb03c494c3.png)



同理，如果只知道对边，那么就要对边长度除以1/2才能得到斜边的长度。

知道了对边和斜边以后，邻边是不是也能求了呢？勾股定理就行了。

知道斜边求邻边就用cos，知道邻边求对边就用tan。



那么聪明的你或许已经想到了怎么求开头的问题了，我们重新来看这幅图

现在我们知道OA的长度是L，那么怎么求OD的长度呢？我们记得邻边和对边的函数是哪个来着？

对了，就是cos，然后在看AD的长度怎么求呢？答案是sin函数。那么根据刚才学的知识，**OA**这个向量的数对表示可以这么写：

### 实现散弹

![图片](images/tutorials/436d50ca19067625ad7a859a.png)

学会了三角函数和向量的各种骚操作以后，我们试着把这些知识放进TR里面吧，制作角度散射的散弹就是一个不错的选择。

我们先随便找一个MOD武器的源码，然后找到Shoot函数，我们从头开始写散弹的发射方法吧。

首先是求出发射向量：

```csharp
// 获取玩家的中心点坐标
Vector2 playerCenter = player.Center;
// 获取鼠标在世界坐标中的位置
Vector2 mousePos = Main.MouseWorld;
// 获取从玩家中心到鼠标的向量
Vector2 vec = mousePos - playerCenter;
```

假设接下来我打算让散弹以-30度，0度，30度这三个角度散射出去，我就需要先求出这个向量的角度，然后利用循环把这个角度转三次。

转完以后我们要把这三个角度都求出来向量值然后以此为弹幕的速度，把弹幕发射出去，要实现这个过程需要用循环：

```csharp
// 求出vec向量的角度，利用tan的反函数，注意，Math.Atan返回的是一个double类型
// double比float类型的精准度高，所以需要强制转换
float rad = (float)Math.Atan2(vec.Y, vec.X);
// i的值从-1到1（包含1）
for (int i = -1; i <= 1; i++)
{
    // 真实射击角度，MathHelper.Pi / 6.0f就是30度角的弧度π/6
    // 乘以i就是让这个角度在-30, 0, 30中的其中一个
    float realRad = rad + i * MathHelper.Pi / 6.0f;
    // 注意，这里得出的是单位向量，也就是长度为1，不是原向量
    Vector2 finalVec = new Vector2((float)Math.Cos(realRad), (float)Math.Sin(realRad));
    // 单位向量乘以16就是16倍的速度
    finalVec *= 16;
    // 获取弹幕来源（1.4.4 新签名需要这个参数）
    var source = player.GetSource_FromThis();
    // 射出去！
    Projectile.NewProjectile(source, position, finalVec, type, damage, knockBack, player.whoAmI);
}
```

当然你可以随意增加这个散射的数量以及散射角度，甚至达到圆形散射。



偷偷告诉你们，其实根本不用写那么多代码，TR为我们把这些计算都封装到了一些函数里面，简版代码如下：

```csharp
Vector2 vec = Main.MouseWorld - player.Center;
// i的值从-1到1（包含1）
for (int i = -1; i <= 1; i++)
{
    Vector2 finalVec = (vec.ToRotation() + i * MathHelper.Pi / 6.0f).ToRotationVector2() * 16;
    // 获取弹幕来源（1.4.4 新签名需要这个参数）
    var source = player.GetSource_FromThis();
    // 射出去！
    Projectile.NewProjectile(source, position, finalVec, type, damage, knockBack, player.whoAmI);
}
```
